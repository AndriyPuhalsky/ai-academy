Python, щоб читати й керувати

Основи · 6 уроків · ≈ 75 хв

Важлива установка: ми не робимо з тебе Python-програміста, що пише все з нуля. Мета цього модуля скромніша й практичніша — навчитися читати код, який пише Claude Code, розуміти, що він робить, і впевнено правити дрібниці. Цього досить, щоб керувати AI свідомо, а не наосліп. Python — наша робоча мова на весь курс, тож знайомимось рівно настільки, наскільки треба.

6.1Навіщо читати код і як запускати Python

Claude Code пише код за тебе — але щоб перевірити, підправити чи зрозуміти, що пішло не так, ти маєш вміти його прочитати. Це як водій, що не мусить бути механіком, але розуміє приладову панель. Саме така ціль: читати й орієнтуватися, а не зубрити синтаксис.

Файл з програмою на Python має розширення .py. Щоб його запустити (виконати), у терміналі пишуть: 

python hello.py        # на Windows
python3 hello.py       # на macOS / Linux (там часто саме python3)

Ось робочий ритм цього модуля — він знадобиться завжди:

flowchart LR
  R["Прочитати код"] --> RUN["Запустити"]
  RUN --> Q{"Працює?"}
  Q -- "Так" --> OK["Готово"]
  Q -- "Ні" --> ASK["Спитати Claude Code:
поясни / виправ"]

Читай → запусти → не працює? спитай Claude Code → повтори. Без паніки

Головна звичка модуля. Будь-який незнайомий код можна вставити Claude Code зі словами «поясни рядок за рядком простими словами». Не соромся — це найшвидший спосіб навчитися читати. Далі ми пройдемо основні «цеглинки», які ти зустрічатимеш постійно.

6.2Змінні й типи: значення з іменами

Змінна — це підписана «коробка» зі значенням. Зустрічатимеш їх у кожному файлі. 

name = "Андрій"        # рядок (str) — текст у лапках
age = 28                # ціле число (int)
price = 19.99           # дробове число (float)
is_active = True        # булеве (bool): True або False
print(name, age)        # вивести значення на екран

Чотири типи покривають майже все, що ти бачитимеш:

  • str — текст у лапках: "Claude";
  • int — цілі числа: 42;
  • float — дробові: 0.7;
  • bool — True / False (так/ні).

Це і є «керування» на практиці. Часто щоб змінити поведінку програми, достатньо знайти потрібну змінну й поміняти її значення — наприклад, число чи текст. Тобі не треба переписувати все: знайшов рядок, змінив значення, запустив. # на початку рядка — це коментар: Python його ігнорує, він для людей.

6.3Списки й словники: набори значень

Дві структури, які ти впізнаватимеш миттєво за дужками.

Список (list) — упорядкований набір у квадратних дужках. Нумерація з нуля:

topics = ["вступ", "термінал", "веб"]
print(topics[0])      # вступ — перший елемент (індекс 0)
print(len(topics))    # 3 — скільки елементів

Словник (dict) — пари «ключ: значення» у фігурних дужках. Звертаєшся за ключем:

user = {"name": "Андрій", "lessons": 3}
print(user["name"])   # Андрій

Впізнаєш? Словник виглядає майже як JSON із Модуля 4 — ті самі пари «ключ: значення». Це не випадково: коли модель чи API повертають дані у JSON, у Python вони стають саме словниками й списками. Тому ці дві структури — твій хліб насущний у роботі з AI.

6.4Умови й цикли: логіка коду

Умова (if) виконує код лише коли щось правда:

score = 82

if score >= 70:
    print("Зараховано")
else:
    print("Спробуй ще раз")

Найважливіше про Python — відступи. Бачиш, що рядки після if зсунуті праворуч (на 4 пробіли)? Саме відступ показує, який код «належить» умові. Це не краса, а синтаксис: те, що зсунуто всередину — виконується в межах if. Зустрічатимеш відступи в циклах і функціях так само.

Цикл (for) повторює дію для кожного елемента набору:

topics = ["вступ", "термінал", "веб"]

for topic in topics:
    print("Тема:", topic)
# Тема: вступ
# Тема: термінал
# Тема: веб

Читається майже як англійська: «для кожного topic у списку topics — виведи його». Цикли — основа обробки даних: пройтися по всіх документах, по всіх відповідях, по всіх рядках.

6.5Функції: іменовані шматки роботи

Функція — це названий блок коду, який щось приймає (аргументи) і повертає результат. Замість повторювати код, його викликають за іменем. Ти бачитимеш функції всюди. 

def greet(name):
    return "Привіт, " + name

print(greet("Андрій"))   # Привіт, Андрій
print(greet("Олено"))    # Привіт, Олено

Розбір. def оголошує функцію, далі її ім'я (greet) і в дужках — аргументи (name). return віддає результат назад тому, хто викликав. Рядок greet("Андрій") — це виклик: ми передаємо значення "Андрій", і функція повертає привітання. Уся програма зазвичай зібрана з таких функцій-цеглинок.

Тобі не треба вміти писати складні функції з нуля — досить упізнавати їх у коді й розуміти: «ось блок, що приймає оце й повертає оте». Цього вистачить, щоб орієнтуватись у будь-якому файлі, який згенерує Claude Code.

6.6Помилки — це нормально (і як їх читати)

Запускаєш код — і замість результату червоний текст? Спокійно: помилки — звичайна частина роботи, навіть у досвідчених інженерів. Коли в Python щось не так, він друкує traceback — «слід» того, де зламалось. Виглядає лячно, але головне правило просте:

Читай знизу вгору. Останній рядок traceback — найважливіший: це сам тип і опис помилки. Наприклад, NameError: name 'nme' is not defined означає, що ти звернувся до змінної nme, якої немає (мабуть, описка в name). Часто вже цього рядка досить, щоб зрозуміти причину.

А найшвидший спосіб полагодити — той самий, що в нашій діаграмі на початку модуля:

Встав Claude Code увесь текст помилки + код і запитай:
"Ось помилка і код. Що це означає простими словами і як виправити?"

Він пояснить причину й запропонує виправлення. Згодом ти й сам читатимеш типові помилки з першого погляду — але навіть тоді вставити traceback помічнику швидше, ніж гадати.

Підсумок. Ти вмієш читати головні «цеглинки» Python — змінні й типи, списки й словники, умови й цикли, функції — і не лякаєшся помилок. Цього рівня достатньо, щоб свідомо керувати кодом, який пише Claude Code. Останній крок Фази A — навчитися безпечно поводитися з ключами доступу. Це наступний модуль.
