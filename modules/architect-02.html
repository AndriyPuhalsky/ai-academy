Готуємо комп'ютер

Старт · 5 уроків · ≈ 50 хв

Це найтехнічніший підготовчий модуль — далі буде легше. Ми разом, крок за кроком, перетворимо твій звичайний комп'ютер на робоче місце AI-інженера. Нічого не пропускай і не поспішай: після кожного кроку є перевірка «що ти маєш побачити». Якщо щось не так — поряд є блок «якщо помилка». Наприкінці в тебе працюватиме команда claude.

П'ять кроків до робочого місця. Йдемо зверху вниз, перевіряючи кожен

2.1Крок 1. Термінал — твій пульт керування

Термінал (його ще звуть командний рядок) — це вікно, де ти даєш комп'ютеру команди текстом. Саме звідси ми запускатимемо все. Спершу навчимося його відкривати.

Windows: натисни клавішу Windows, набери PowerShell, відкрий застосунок «Windows PowerShell» (або «Terminal», якщо є).

macOS: натисни Cmd+Пробіл, набери Terminal, натисни Enter.

Linux: зазвичай Ctrl+Alt+T, або знайди «Terminal» у меню застосунків.

Відкрилося темне (або світле) вікно з курсором. Перевіримо, що все живе — впиши команду й натисни Enter:

pwd

Що ти маєш побачити. Рядок зі шляхом до поточної папки, наприклад /Users/ім'я (macOS), /home/ім'я (Linux) або C:\Users\ім'я (Windows). Це означає «зараз я знаходжусь ось у цій папці». pwd = «print working directory».

Ще три команди, які знадобляться постійно (спробуй кожну):

ls            # показати файли в поточній папці (на Windows PowerShell теж працює)
cd Desktop    # зайти в папку Desktop (робочий стіл)
cd ..         # піднятися на рівень вище

Не треба запам'ятовувати все. Цих кількох команд вистачить надовго. Термінал лякає лише перші 10 хвилин — далі він стане звичним, як будь-яке вікно.

2.2Крок 2. Встановлюємо Node.js

Node.js — це програма, без якої не запуститься Claude Code (він на ній побудований). Встановимо її.

Windows і macOS (найпростіший шлях):

  1. Відкрий у браузері nodejs.org.
  2. Завантаж версію з позначкою LTS (це стабільна версія «для всіх»).
  3. Запусти завантажений файл і тисни «Далі/Continue» до кінця, нічого не міняючи.

Linux (Debian/Ubuntu) — у терміналі:

sudo apt update
sudo apt install -y nodejs npm

(На інших дистрибутивах — свій менеджер пакетів, або встанови з nodejs.org.)

Перевірка. Закрий і знову відкрий термінал (щоб він «побачив» нову програму), потім впиши:

node --version
npm --version

Що ти маєш побачити. Два рядки з номерами версій, наприклад v20.11.1 і 10.2.4 (числа в тебе можуть бути іншими — це нормально). Якщо обидва номери з'явилися — Node.js встановлено успішно. npm — це «магазин» бібліотек, що ставиться разом із Node; ним за хвилину поставимо Claude Code.

Якщо помилка на кшталт command not found чи «не є внутрішньою командою»: 1) переконайся, що ти закрив і відкрив термінал заново після встановлення; 2) якщо не допомогло — перевстанови Node.js із nodejs.org і перезавантаж комп'ютер. Це найчастіша причина, і вона легко лікується.

2.3Крок 3. Акаунт Anthropic і оплата

Claude Code звертається до моделі Claude, а це платна послуга. Тому потрібен акаунт із налаштованою оплатою. Зробимо це до встановлення — щоб потім усе запрацювало одразу.

  1. Відкрий console.anthropic.com і зареєструйся (або увійди, якщо акаунт уже є).
  2. Знайди розділ оплати (зазвичай «Billing» / «Plans & billing» у налаштуваннях) і додай спосіб оплати та трохи коштів на баланс або підписку.

Скільки це коштує. Ти платиш за фактичне використання, і для навчання суми зазвичай невеликі. Але це реальні гроші — заклади невеликий стартовий бюджет. Точні актуальні тарифи й варіанти доступу завжди дивись на офіційній сторінці docs.claude.com (ціни змінюються, тому єдине надійне джерело — офіційне).

Порада з безпеки. У консолі можна виставити ліміт витрат (spending limit). Постав невелику межу на старті — так ти точно не витратиш більше, ніж планував, поки вчишся.

2.4Крок 4. Встановлюємо Claude Code

Тепер головне. У терміналі впиши одну команду (вона працює однаково на Windows, macOS і Linux, бо ми ставимо через npm із кроку 2): 

npm install -g @anthropic-ai/claude-code

Прапорець -g означає «global» — встановити для всієї системи, щоб команду claude можна було викликати з будь-якої папки. Встановлення триватиме кілька секунд — побіжать рядки тексту, це нормально.

Перевірка:

claude --version

Що ти маєш побачити. Номер версії Claude Code (наприклад, 1.x.x). З'явився — інструмент встановлено.

Якщо помилка про доступ (EACCES, «permission denied») на macOS/Linux: не став через sudo наосліп — краще налаштувати окрему теку для глобальних пакетів npm. Найшвидше — відкрий офіційну інструкцію зі встановлення на docs.claude.com і виконай кроки звідти: вони завжди актуальні під твою систему.

Важливо. Команда встановлення й вимоги можуть із часом змінюватися. Якщо рядок вище не спрацював або десь читаєш інакший — орієнтуйся на офіційну сторінку встановлення Claude Code. Звіряти кроки з документацією — нормальна щоденна звичка інженера, не виняток.

2.5Крок 5. Перший запуск і вхід

Створимо окрему папку для першого проєкту й зайдемо в неї — щоб не захаращувати систему:

cd Desktop          # перейдемо на робочий стіл (або куди зручно)
mkdir ai-start      # створимо папку ai-start
cd ai-start         # зайдемо в неї

Тепер запускаємо Claude Code прямо в цій папці:

claude

Під час першого запуску Claude Code попросить тебе увійти. Зазвичай він відкриє браузер (або дасть посилання), де треба підтвердити вхід у твій акаунт Anthropic і дозволити доступ. Підтверджуєш — і повертаєшся в термінал.

Що ти маєш побачити. Після входу термінал перейде в режим розмови з Claude Code: з'явиться запрошення щось написати (поле вводу й, можливо, вітальний текст). Це означає, що все працює — інструмент готовий приймати твої задачі.

Якщо помилка. Якщо claude «не знайдено» — закрий і відкрий термінал заново (як із Node.js). Якщо не вдається увійти — перевір, що акаунт і оплата налаштовані (крок 3) і що в консолі є доступ/баланс. Будь-яку незрозумілу помилку можна скопіювати й пошукати на docs.claude.com.

Поки що нічого більше не роби — просто переконайся, що дійшов до режиму розмови. Як вийти: зазвичай команда /exit усередині, або сполучення Ctrl+C кілька разів. У наступному модулі ми вже поставимо Claude Code першу справжню задачу.

Підсумок. Ти відкрив термінал, встановив Node.js, створив акаунт із оплатою, поставив Claude Code і вперше зайшов. Це був найтехнічніший етап — далі починається найцікавіше: ти збудуєш першу річ, керуючи AI.

Квіз: перевір себе

П'ять питань, щоб закріпити кроки. Обирай відповідь — і одразу бачиш пояснення.

Комп'ютер готовий?

Познач модуль завершеним — і відкриється Модуль 3, де ми поставимо Claude Code першу задачу.
