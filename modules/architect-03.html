Перша розмова з Claude Code

Старт · 4 уроки · ≈ 40 хв

Настав момент першої перемоги. Зараз ти, не написавши жодного рядка коду власноруч, збудуєш справжню вебсторінку — просто пояснивши Claude Code словами, чого хочеш. Це і є головний навик курсу: чітко поставити задачу, подивитися, що пропонує AI, підтвердити — і отримати результат.

3.1Запускаємо Claude Code у папці проєкту

Важливе правило: Claude Code працює всередині папки, у якій ти його запустив — саме там він створюватиме й змінюватиме файли. Тому спершу заходимо в потрібну папку, а вже потім запускаємо. Використаємо ту, що створили в минулому модулі: 

cd Desktop/ai-start    # заходимо в нашу папку проєкту
claude                 # запускаємо Claude Code саме тут

Що ти маєш побачити. Термінал перейшов у режим розмови: внизу є поле, куди можна друкувати текст. Тепер термінал «слухає» тебе як співрозмовника, а не чекає системних команд. Можеш звертатися звичайними словами українською.

Спробуй просто привітатися — напиши в поле, наприклад: «Привіт! Поясни в двох реченнях, що ти вмієш робити» — і натисни Enter. Claude Code відповість текстом. Це твоя перша розмова.

Підказка. Звертайся до Claude Code, як до колеги-інженера: кажи, що треба, а не як це писати в коді. «Зроби сторінку з кнопкою» — гарна задача. Деталі він спитає або запропонує сам.

3.2Цикл роботи: проси → дивись → підтверджуй

Перш ніж будувати, зрозумій, як Claude Code діє — це знімає весь страх. Він не робить змін мовчки за твоєю спиною. Він працює циклом і питає твого дозволу, перш ніж щось змінити чи запустити: 

sequenceDiagram
  participant Ти as Ти
  participant CC as Claude Code
  Ти->>CC: задача словами
  CC-->>Ти: пропонує, що зробити (показує зміни)
  Ти->>CC: підтверджуєш (так / ні)
  CC->>CC: створює файли, запускає команди
  CC-->>Ти: показує результат
  Note over Ти,CC: не подобається — просто проси переробити

Ти завжди головний: Claude Code пропонує, ти схвалюєш або відхиляєш

На практиці це виглядає так: ти описав задачу — Claude Code показує, які файли хоче створити чи змінити (і запитує підтвердження). Ти погоджуєшся — він виконує. Якщо результат не той — просто кажеш словами, що поправити. Жодних незворотних дій без твого «так».

Чому це безпечно й комфортно. Оскільки нічого не змінюється без твого підтвердження, ти можеш сміливо експериментувати. Не зрозумів, що він пропонує? Напиши «поясни, що ця зміна робить і навіщо» — і тільки потім підтверджуй.

3.3Перша збірка: своя вебсторінка

Тепер найприємніше. У режимі розмови з Claude Code (поле вводу) встав таку задачу звичайними словами: 

Створи просту вебсторінку у файлі index.html: великий заголовок
"Моя перша AI-сторінка" і кнопка "Привітатись", яка по натисканню
показує спливне повідомлення "Все працює!". Зроби приємний вигляд.

Claude Code запропонує створити файл index.html і покаже його вміст. Підтвердь створення (погодься, коли він спитає). За кілька секунд файл з'явиться у твоїй папці ai-start.

Тепер відкриємо результат у браузері. Це можна зробити двома шляхами:

  • Найпростіше: відкрий папку ai-start у провіднику/Finder і двічі клацни по файлу index.html — він відкриється у браузері.
  • Або прямо з терміналу (відкрий нове вікно терміналу в тій самій папці) однією з команд:
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux

Що ти маєш побачити. У браузері — сторінка з твоїм заголовком і кнопкою. Натискаєш кнопку — вискакує повідомлення «Все працює!». Вітаю — ти щойно створив і запустив свою першу програму, керуючи AI. Це і є та сама «перша перемога».

Якщо щось не так. Сторінка порожня чи кнопка не реагує? Повернись у Claude Code і просто опиши проблему словами: «кнопка не показує повідомлення, виправ, будь ласка». Він подивиться й полагодить. Уміння спокійно описати проблему — половина роботи інженера.

3.4Корисні звички з перших днів

Кілька прийомів, які зроблять роботу з Claude Code приємною й продуктивною:

  • Ітеруй маленькими кроками. Не проси все одразу. Зробив сторінку — тепер «зроби кнопку синьою», потім «додай поле для імені». По шматочку — простіше й зрозуміліше.
  • Проси пояснювати. «Поясни простими словами, що ти щойно змінив» — і ти навчаєшся по ходу, а не просто отримуєш результат.
  • Не бійся помилок. Зламалося — опиши словами, що бачиш. Це нормальна частина процесу, а не катастрофа.
  • Команди-службовці. Усередині Claude Code є команди, що починаються зі слешу — наприклад, /help покаже доступні можливості, а /exit вийде. Спробуй /help зараз, щоб роззирнутися.

Де «живе» твій проєкт. Усі файли, які створює Claude Code, лежать у тій папці, де ти його запустив (ai-start). Це звичайні файли — їх видно у провіднику/Finder, їх можна відкривати, копіювати, видаляти. Ніякої магії: AI просто створює файли замість тебе.

Підсумок Фази 0. Ти налаштував комп'ютер і вже збудував першу вебсторінку, керуючи AI. Ти зрозумів головний цикл: проси → дивись → підтверджуй. Далі, у Фазі A, ми трохи зазирнемо «під капот» того, що ти створив: що таке ці файли, як влаштований веб, і як зберігати свою роботу через Git. Поступово, без поспіху.
