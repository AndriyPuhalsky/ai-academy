## Рішення власника 2026-09-07 (перед запуском конвеєра)

Три питання з `04-package/docs/open-decisions.md` закриті. **Не переоткривати.**

### Р-1 · Аркуш акаунта — ТАК, робимо (закриває питання 1, розблоковує етап 5)

У шапці лишається **аватар + імʼя**; «Сертифікати» і «Вийти» переїжджають у аркуш
акаунта, який відкривається кліком по аватару. Слот фіксується на **192 px**, CLS = 0
за конструкцією.

⚠ **Доручення дизайн-сесії і `open-decisions.md` тут суперечили одне одному** (перше
казало «переносити», друге — «без відповіді лишати чотири елементи»). Власник обрав
перенесення. Суперечність закрита цим рядком.

**Аркуш НЕ треба вигадувати.** Пакет уже побудований під нього:
- `files/css/components.css:1206–1213` — `.ds-hdr__slot { width: var(--hdr-slot-w) }`,
  `:root { --hdr-slot-w: 192px }`, і коментар прямо каже: «Сертифікати й вихід переїхали
  в аркуш акаунта, який той аватар і відкриває»;
- `files/css/components.css:1216–1225` — `.ds-btn--name` (12ch + трикрапка, зникає ≤640);
- сам аркуш — це **той самий уже намальований дропдаун**, що й «Курси»:
  `.ds-nav__group` + `.ds-nav__trigger[aria-expanded]` + `.ds-nav__menu`
  (`components.css` C4, рядки 1264–1273) з клавіатурним контрактом §6.3.

Тобто фронтендер **збирає аркуш із наявних компонентів**, а не малює новий візуал.
Якщо в процесі виявиться, що чогось у системі бракує, — **стоп і питання**, не вигадка.

### Р-2 · Кегль коду на мобілці — варіант **A**, плаский 13,52 px

Уже в пакеті, робити нічого не треба. `@media (max-width: 640px) { --fs-code: … }`
**не додавати**. Підстава: переміряно по 677 рядках терміналів — B прибирає скрол
приблизно для одного рядка з пʼятнадцяти (45,3 % → 38,4 %), тобто платимо кеглем майже ні
за що.

### Р-3 · PM-агента не запускаємо

Пакет уже містить те, що зазвичай робить PM: порядок робіт по етапах, карту міграції на
390 імен, критерії приймання, 38 пасток, дифф до `js/`. Переказ цього своїми словами —
ризик розбіжності з пакетом, а розбіжність = регресія. Тому `01-plan.md` у цій задачі
**немає свідомо**; його роль виконує `04-package/docs/P3-order.md`.

### Що лишається як записано в пакеті, без окремого рішення
- `backdrop-filter` у шапці — **немає** (питання 3 було записом, а не питанням).
- Критерій приймання 17 читається як «≤ 1 ScrollTrigger на лендінгу Термінала,
  ≤ 2 на роадмапі, 0 на решті 64 сторінках» (питання 4 — виправляється критерій, не код).
- Scroll-spy у змісті довідника **не додаємо** — сьогодні його немає, розширення обсягу.
- Шість видимих змін В1–В6 (`open-decisions.md`) приймаються як є: заголовок уроку
  48 → 64 px, знятий капслок у пʼяти місцях роадмапа, світліший непройдений відрізок
  змійки, обгортки на 10 таблицях AI Академії, колонка 672/768, вищі пункти навігації.
