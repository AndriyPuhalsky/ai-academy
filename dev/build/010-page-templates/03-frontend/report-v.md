Перша форма бере робочу копію рівно названих файлів і не чіпає чужий індекс; друга бере весь індекс. Я знав правило «ніколи `git add -A`» і виконав його — але воно **не захищає від того, що в індекс поклав хтось інший**.

### `js/ui.js` — `streamHero()` треба замінити на `typeHero()`

**Чому.** Розмітка обох класичних лендінгів уже стоїть на `.ds-hero__type` (clip-path + `steps()`), але друком керує `streamHero()`, який **вставляє текст у DOM посимвольно** — те, що система забороняє (M10: ~30 записів у DOM на рядок, зірване виділення тексту, стільки ж перечитувань скрінрідером). Зараз не зламано: `.ds-hero__type` без `.is-typing` просто повністю відкритий. Але після етапу 9 із `custom.css` зникнуть `.js [data-stream] { visibility: hidden }` і `.caret`, і лендінги лишаться з посимвольною вставкою без оформлення.

**Готовий код** (форма з `_check/b1/js/landing.js:264–289`; замінює `tokenize()`, `delay()`, `streamHero()`):

```js
/* ---------- 1. M10 · друк заголовка: clip-path + steps(), НУЛЬ записів у DOM ---------- */
function typeHero() {
  var parts = Array.prototype.slice.call(document.querySelectorAll("[data-stream]"));
  var caret = document.getElementById("heroCaret");
  if (!parts.length) return;
  var M = AIA.motion;
  var cps = (M && M.cps) ? M.cps() : Infinity;
  /* ⚠ П5 · швидкість — єдиний токен, на який ДІЛЯТЬ, тому вона не множиться
     на --motion. Гілку вимкнення бере саме цей рядок: cps === Infinity
     означає «рух вимкнено» → текст просто стоїть на місці. */
  if (!isFinite(cps) || cps <= 0) {
    parts.forEach(function (el) { el.classList.remove("is-typing"); });
    if (caret) caret.setAttribute("data-gone", "");
    return;
  }
  var pause = M.dur("state");          /* пауза між рядками — токен, не число */
  var acc = 0;
  parts.forEach(function (el) {
    var n = (el.textContent || "").length;
    el.style.setProperty("--hero-steps", n);
    el.style.setProperty("--hero-type-dur", (n / cps) + "s");
    el.style.setProperty("--hero-type-delay", acc + "s");
    el.classList.remove("is-typing");
    void el.offsetWidth;               /* рестарт анімації без таймера */
    el.classList.add("is-typing");
    acc += n / cps + pause;
  });
  if (caret) caret.removeAttribute("data-gone");
}
```

Далі в `init()` — `typeHero()` замість `streamHero()`. Розмітка готова, HTML правити не треба.

## Що передати тестувальнику

1. **Друк hero Термінала.** Змінена механіка. Ламати: перезавантажити з порожнім кешем → штора за **~1,5 с**; «↻ показати ще раз» має перезапускати; **звузити вікно нижче 640** — сесія перемальовується вузьким варіантом і має надрукуватись **ще раз**.
2. **Копіювання з термінала.** Виділити текст у `.term--hero` і скопіювати → у буфері **байт у байт**. Я перебудував розмітку рядків, тому це головна регресія, яку варто шукати. Переноси лишились **у потоці `<pre>`, поза `.term__line`**.
3. **⚠ Порядок скриптів.** `js/motion.js` мусить лишатись **після** GSAP на `claude-code.html`.
4. **Поява секцій на Терміналі.** 25 вузлів `[data-reveal]`. Ламати: клікнути «Програма» (якірний стрибок через пів сторінки) — секції лишаться `armed`, поки не проскролити назад. Це поведінка спільного `motion.js`, не властивість моєї розмітки.
5. **`ds-tbl__wrap--tall`.** Колесо над таблицею має спершу прокрутити її, а на межі — віддати скрол сторінці.
6. **Зміст довідника.** На 1023 → 1024 і назад. Скрипт згортає зміст **лише при завантаженні**, не на `resize` — форма з пакета.
7. **⚠ Пастка вимірювання, на яку я витратив пів години.** У щойно створеному `iframe` `matchMedia()` під час парсингу бачить **`innerWidth === 0`**. Тому скрипт змісту в iframe завжди згортає його — навіть на 1440. На реальній сторінці `open: true`. **Не роби висновок про зміст довідника з iframe-стенда.**
8. **Кеш.** `Ctrl+F5` не оновлює `css/*.css` і `js/*.js`.
9. **Координати.** 1440 CSS px → скріншот 1568 px (×1,089).
10. **Спільний браузер.** Троє агентів в одній вкладковій групі: моя вкладка регулярно ставала `visibilityState: "hidden"`, і тоді **IntersectionObserver не доставляє жодного колбека** (П-10).

## Знайдене поза обсягом

**Для кореневої сесії / Ф-Д (етапи 8–9):**
1. 🔴 **`js/ui.js:58–91` — `streamHero()`** (див. вище). Без заміни після видалення `custom.css` два лендінги лишаться з посимвольною вставкою в DOM і без оформлення каретки.
2. **`js/config.js` → `donationCard()`, гілка `type: "copy"`.** Заміряно на `index.html` 1440: значення в `.ds-code__pre` (IBAN 37 символів, USDT-адреса 34) **обрізається** з горизонтальним скролом усередині картки. Причина — `white-space: pre` проти картки ~296 px у три колонки. Реквізит, якого не видно цілком, — сумнівна ціль для «скопіювати».

**Для Ф-Б — стосується всіх 111 таблиць уроків:**
3. **`overflow-wrap: anywhere` у `.ds-tbl th, .ds-tbl td`** (`components.css` §13) розриває **всередині слова**, коли колонка вузька. Побачив очима: заголовок «Область» рендериться як «Област / ь». Правило потрібне для довгих ключів у першій колонці, але на заголовках дає видимий брак. Кандидат на `overflow-wrap: break-word` для `th` окремо — рішення власника системи.

**Загальне:**
4. **Твердження звіту Ф-А про порядок каскаду.** Підтверджую незалежно: Tailwind CDN вставляє свій `<style>` у кінець `<head>` незалежно від позиції `<script>`, тому перестановка `<link>` на каскад не впливає.
5. **`.ds-hero__glow` має видимий вертикальний зріз** по межі `.ds-wrap` (заміряно: підсвіт обривається на x = 144 при вікні 1440). Причина структурна: у кадрі Б1 `.ds-hero` — та сама коробка, що й `.ds-wrap`, а градієнт заданий у відсотках від неї. **Розмітка дослівно як у кадрі**, тобто це властивість макета. Якщо власник захоче підсвіт на всю ширину — один рядок у `components.css` §24, чужа зона й окреме рішення.
