**Виправив сам (за живим джерелом, показаним у звіті):** «окремої програми `cd` на диску не

прибрано; «дослівні команди з документації» → «взяті з документації» (у доксах повний рядок
присвоєння); «всі інструкції Claude Code розраховані на PowerShell» → «основні» (докси дають

«псевдонім» пояснено; «консольна», «дистрибутив», «файловий менеджер» замінені на слова без
терміна. Заборонених зворотів — нуль. Diff 14+/13−, `check-lessons` ✓, `check-quiz --verify` OK.

**Непідтверджене, не правлено (рішення автора/власника):** «`PATH` — рядок, склеєний
двокрапками» правда лише для macOS/Linux, а абзацом вище названий PowerShell (там `;`);

на native-збірку 2026-09-05 — датований знімок, не помилка.

**Суперечність контракту §4 — три кнопки «Копіювати»:** `t1` — сесія з шести команд (у читача
`cd images` впаде), `t2` — три незалежні діагностичні команди, серед них `claude --version`,

папку без `README.md`. Найдешевший фікс — прибрати кнопку й `.term--cmd` у `t1`–`t3`; це
видима зміна, рішення власника.

**Пропущених тем немає**, усі шість пунктів програми покриті. Урок ніде не лінкує
