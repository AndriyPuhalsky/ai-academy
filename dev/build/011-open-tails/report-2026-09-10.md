# 011 · Звіт кореневої сесії 2026-09-10 — доопрацювання реєстру хвостів

Сесія працювала за вказівкою власника: «спочатку роби всі свої задачі (рядки «Я»), потім
напишеш», з двома правилами зверху — **не погіршувати наявний UI/UX і функціонал** і
**пропонувати зміни з урахуванням наслідків**. Усе нижче — на гілці `dev`, без мержу.

Метод: власний Chrome по CDP (рецепт QA 010) + локальний `http.server`. Кожна правка має
замір «до» (незмінна копія `HEAD` у другому сервері, порт 8312) і «після» (робоче дерево,
порт 8311). Стенд перенесено в `stand/` цієї папки, щоб наступна сесія могла повторити.

## Знахідки поза реєстром (не правив, для власника)

- **`aia:config-ready` на уроках чекає завантаження `mermaid.min.js` з CDN** (класичний `<script>` у
  кінці body блокує `DOMContentLoaded`): на холодному кеші сайдбар, навігація й замок для
  залогіненого зʼявляються на ~1,2–1,5 с пізніше, ніж могли б. Лікується `async`-завантаженням
  Mermaid із самого `mermaid-init.js` (57 файлів + init) — окреме рішення.
- Гість на заблокованому уроці тепер одразу бачить замок, а не урок на 1,5–4 с — це
  зачіпає й Googlebot (він гість). Раніше він теж отримував замок після гідратації, тож
  індексації це не змінює, але варто знати.
- Кеш Chrome у стенді віддає старі `css/js` (та сама пастка №1 з 010): у `stand/cdp.mjs`
  кеш тепер вимкнено завжди. Фальшивий ключ сесії, який стенд кладе в `localStorage`, щоб
  обійти замок, ЛИШАЄТЬСЯ в origin — гостьові заміри після нього хибні (t10 це спіймало).

## Як продовжити (наступна сесія)

1. `cd dev/build && claude` — конвеєр і памʼять агентів працюють лише звідти.
2. Стенд: `python3 -m http.server 8311` з кореня; Chrome за рецептом
   `dev/build/.claude/agent-memory/aia-build-qa/method_cdp_own_chrome.md` (порт 9333);
   скрипти — `dev/build/011-open-tails/stand/*.mjs` (`S=<тека для знімків> node t5-verify.mjs`).
3. Дозняти: `t10-gate.mjs` (замок гостя), `t9-hero-reserve.mjs` (резерв hero + CLS),
   `t5-verify.mjs` секція 6 (меню з компенсацією), `t3b-lines.mjs` база/після + порівняння
   рядків першої клітинки, `t8-fade.mjs` — очима по знімках.
4. Далі — QA-хвиля на dev-превʼю (апрув власника), потім реліз.
