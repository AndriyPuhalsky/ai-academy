# Програма курсу «AI Термінал» — джерело правди

**Затверджено власником 2026-09-03** після звірки фактури двома агентами-дослідниками
(`facts-c01-c08.md`, `facts-c09-c16.md`, 55 файлів дослівного виводу в `screens/`).

**Цей файл головніший за план `~/Desktop/claude-code-course-plan.local.md`.** Той писався
2026-08-24 і розійшовся з реальністю: у ньому 16 модулів, чотири режими дозволів і вісім
hook-подій. Насправді — 22 модулі, **шість** режимів дозволів і **33** hook-події.

---

## Три рішення власника, на яких стоїть програма

| # | Рішення | Наслідок |
| - | ------- | -------- |
| 1 | **22 модулі + фінальний іспит** замість 16 | 23 рядки в `modules`. Обидва дослідники незалежно довели, що 16 не вміщають матеріал: `c04`, `c06`, `c09`, `c12`, `c14` старої нумерації переповнені, а чотирьох тем немає взагалі |
| 2 | **Курс орієнтується на канал `latest`**, не на homebrew stable | Екрани знімаються зі свіжої збірки; біля кожного стоїть версія. Локальний `claude` перевстановлюється офіційним інсталятором **до** початку авторингу |
| 3 | **Довідники — окремі сторінки без квізу й прогресу** | Не мають рядків у `modules`, не входять у сертифікат. До них повертаються, їх не «проходять» |

**Ціна рішення 1, названа прямо:** зникає відповідність «заняття школи N = модуль `cNN`»,
ухвалена 2026-08-27. Сайт і школа стають різними продуктами з різною нарізкою. Мапа
відповідності — у кінці цього файлу, щоб зв'язок не загубився.

**Чому `c07` і `c08` окремо:** дослідник назвав старий об'єднаний модуль «найщільнішим у
курсі й водночас найважливішим для безпеки». Шість режимів + правила + protected paths +
класифікатор + пісочниця в один модуль не вміщаються.

**Чому гроші окремим модулем:** у старому плані ціна була розмазана по чотирьох модулях
(кешування в контексті, ціни в моделях, `/usage` в інтерфейсі, ліміти в моделях). Для
безкоштовного курсу з масовою аудиторією це критична тема, і вона одна.

**не падає** — друкує кореневий хелп, бо `config` розбирається як звичайний промпт. Будь-який
туторіал із `claude config set` мертвий. Це ідеальний приклад для тези курсу «звіряй живою
командою».

## Наскрізні правила авторингу

1. **Версія біля кожного екрана.** Докси випереджають будь-яку встановлену збірку; на
   2026-09-03 розрив між доксами й локальною 2.1.236 склав ~20 версій. Курс без версії
   на екрані застаріє так само тихо, як застарів план від 2026-08-24.
2. **Жодного вигаданого виводу.** Тільки реальний запуск або дослівна документація.
   Інтерактивні екрани, які зняти неможливо, описуються словами з посиланням, а не
   домальовуються.
3. **Скелет уроку — вісім блоків:** навіщо це · як виглядає на екрані (компонент «термінал»)
   · як працює (Mermaid) · зроби сам · **як перевірити, що вийшло** · типові граблі ·
   **часті питання** · підсумок і наступний крок.
4. **Мінімум одна Mermaid-діаграма на модуль.**
5. **Квіз — 5–6 питань**, кожне з поясненням правильної відповіді.
6. **`timeout` на macOS відсутній** — якщо в курсі будуть приклади з ним, потрібна виноска
   (перевірено дослідником: він обгортав запуски в `perl -e 'alarm N; exec @ARGV'`).
