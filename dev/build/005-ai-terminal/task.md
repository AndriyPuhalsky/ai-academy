# 005 — AI Термінал: повний курс Claude Code CLI з нуля

## Блок 1 — заповнює власник

- **Статус:** в роботі
- **Заведено:** 2026-09-03
- **Платформа:** новий третій блок «AI Термінал» (окремий конфіг `claude-code.config.json`)
- **Дизайн:** `dev/design/005-ai-terminal/` — компонент «термінал» потоком Б зі схваленого
  прототипу, лендінг `claude-code.html` — окремий бриф

### ТЗ

Розписати повноцінний курс «AI Термінал» про Claude Code CLI — ідеальну інструкцію для
людини, яка взагалі нічого не знає про Claude Code, і яка в кінці володіє ним на
професійному рівні. Скрізь явні приклади роботи в терміналі, максимум діаграм і схем,
гарний дизайн з анімацією сторінки, тести, сертифікат.

### Рішення власника 2026-09-03 (відповіді на уточнення)

1. **Ритм:** каркас + 3 еталонні модулі як планка якості → показ власнику → далі хвилями
   по 3–4 модулі до всіх 22. Не «усі одним прогоном».
2. **Дизайн:** компонент «термінал» переносимо потоком Б зі схваленого прототипу в
   `~/Desktop/ai-terminal-course.html`; на лендінг `claude-code.html` — окремий бриф з
   анімацією; сторінки модулів — наявна дизайн-система + GSAP-рух.
3. **Перевірка знань:** 5–6 питань на модуль з поясненням кожної відповіді · у кожному
   уроці блок «зроби сам» із критерієм «як перевірити, що вийшло» · окремий **фінальний
   іспит-модуль** (~25 питань, вищий `passing_score`) → сертифікат за 22 модулі + іспит.
4. **Джерело екранів:** реальний запуск безпечних команд локально + звірка з офіційною
   документацією. GUI-скріншоти (VS Code, Desktop, `/usage`) поки не робимо.

### Рішення власника 2026-09-03, ухвалені після звірки фактури

5. **Програма — 22 модулі + фінальний іспит**, а не 16. Обидва дослідники незалежно довели,
   що 16 не вміщають матеріал. Повна програма — `00-research/program.md`, **вона головніша
   за план на робочому столі**. Наслідок, названий прямо: зникає відповідність «заняття
   школи N = модуль cNN»; мапа зв'язку — в кінці `program.md`.
6. **Курс орієнтується на канал `latest`**, не на homebrew stable. Локальний `claude`
   перевстановлюється офіційним інсталятором **до** початку авторингу — інакше екрани
   знімаються зі збірки, що відстає від доксів на ~20 версій.
7. **Три довідники — окремі сторінки без квізу й прогресу**, поза таблицею `modules`
   і поза сертифікатом: усі слеш-команди й клавіші · таблиця 33 hook-подій · ключі
   `settings.json`.

### Чого точно НЕ робити

- Не переписувати наявні курси (AI Академія, AI Architect) — лише крос-посилання.
- Не змінювати `js/auth.js`, `js/config.js`, `js/module.js`, `js/progress.js`,
  `js/quiz.js`, `js/certificate.js`, `js/verify.js`, `wrangler.toml` — каркас
  перевикористовується як є. Виняток лише якщо воротний крок покаже дефект у `submit_quiz`.
- Не вигадувати вивід терміналу з голови — тільки реальний запуск або дослівна документація.
- Ніяких `apply_migration` від агента: міграції — файлами, застосовує власник.
