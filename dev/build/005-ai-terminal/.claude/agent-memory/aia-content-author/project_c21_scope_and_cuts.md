`c21` — останній змістовний урок курсу «AI Термінал»; його завдання складати вивчене, а не
вводити нове.

**Why:** двадцять модулів пояснили механізми поодинці, і після них лишається без відповіді
питання «у якому порядку це вмикати щодня». Тому урок побудований навколо одного циклу з
доксів — **Explore → Plan → Implement → Commit (чотири фази, не п'ять)**, де перевірка не
фаза, а наскрізна вимога з окремого розділу перед циклом.

**How to apply:**

- **Не переказувати `c21` в іспиті як «ще один набір команд».** Його теза одна: *дай Claude
  перевірку, яку він може запустити сам*. Чотири рівні жорсткості гейта — у промпті →
  `/goal` → Stop-хук (**стеля 8 блокувань поспіль**) → друга думка (`/code-review`).
- **Взято в урок:** `/code-review` (рівні `low…ultra`, `--fix`, `--comment`, фон і власне
  контекстне вікно, запам'ятовує останній рівень) · межа з `/simplify`, `/security-review`,
  `/verify`, `/run`, `/run-skill-generator` · стилі відповіді (п'ять вбудованих,
  `keep-coding-instructions: false` за замовчуванням **знімає** інженерні інструкції,
  читаються раз на старті, не діють на субагентів, `/output-style` видалена у v2.1.91) ·
  статус-лайн · `attribution` / `includeGitInstructions` / `prUrlTemplate` · п'ять
  антипатернів `best-practices` · доступність: `--ax-screen-reader`,
  `CLAUDE_AX_SCREEN_READER`, `axScreenReader`, `prefersReducedMotion`,
  `CLAUDE_CODE_ACCESSIBILITY`, теми `*-daltonized`, `/voice`, `/keybindings`.
- **Свідомо віддано іншим:** керована служба Code Review для GitHub (PR-огляди, `REVIEW.md`,
  рівні 🔴/🟡/🟣, ціни) — це Team/Enterprise і тема `c22`; повна таблиця полів JSON
  статус-лайна (~40 полів, `prompt_cache`, `rate_limits`) — довідник `ref-settings`; 26 груп
  дій у `keybindings.json` — довідник `ref-commands`.
- **Шостий підтверджений розрив версій, придатний для питання іспиту:** стиль **`Concise`
  потребує v2.1.237**, а встановлена збірка — **2.1.236**. Доказ живий:
  `strings "$(which claude)" | grep -c Concise` → **0**, при `Explanatory` → 8 і контрольній
  вигаданій назві → 0. Пошук обов'язково **з великої літери**: слово `concise` з малої в
  бінарнику трапляється часто, це звичайне англійське слово в промптах.
