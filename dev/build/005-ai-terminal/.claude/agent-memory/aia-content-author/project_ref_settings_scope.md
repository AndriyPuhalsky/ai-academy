`claude-code-ref-settings.html` (корінь сайту, ~139 КБ) — усі **223 ключі**
`settings.json` у 17 темах, у трьох колонках: ключ · що робить · **область**.

**Why:** тема довідника — не «що вміє кожен ключ», а «звідки він діє». Найчастіша поразка
з налаштуваннями — правильно написаний ключ у файлі, з якого він мовчки не застосовується.
Тому перед таблицями стоїть розділ із дев'яти пасток, і кожна з них — про область, а не
про синтаксис.

**How to apply:**

**Таблиці генеруються скриптом, не пишуться руками.** Живий `settings-reference.md`
(422 КБ) містить машиночитану таблицю «All settings» — рядки `| [`ключ`](#…) | опис |
тема | область |` між заголовком `## All settings` і першим `## Model and responses`.
Парситься за пʼять рядків Python; описи перекладаються вручну в окремий словник
`key → укр. опис`, HTML збирається з двох частин. Перевірка покриття — різниця множин
ключів словника й таблиці має бути порожня з обох боків.

**Діф проти знімка робиться `comm`, і він щоразу щось знаходить.**
`b-settings-keys-full.txt` (222 ключі, 2026-09-03) проти живої сторінки (2026-09-04) —
рівно один новий ключ, `permissions.blockReadsOutsideWorkingDirectories`. Решта рядків
збіглася побайтово (крім зворотних лапок, які знімає парсер).

**Колонка «версія» — теж машинна, але з ручною фільтрацією.** Регулярка по кожному запису
ключа ловить `Requires Claude Code vX.Y.Z or later.`, **але половина таких речень стосується
підповедінки, а не самого ключа** (`apiKeyHelper` вимагає 2.1.246 лише для оновлення
протермінованого JWT; `disableAllHooks` — лише для хуків Agent SDK). Брати тільки ті, де
речення стоїть окремо; решту читати очима. Після фільтра лишилось 45 ключів із версією,
з них 11 новіші за встановлену 2.1.236.

**Розрив версій на 2026-09-04 — 24 релізи:** `latest` у npm **2.1.260**, локально 2.1.236.
Це більше, ніж записані раніше «~15» і «~20»: розрив зростає, бо машину не оновлювали.

**Що свідомо не пішло у сторінку** (щоб не шукати вдруге):
- **типи й значення за замовчуванням кожного ключа** — це друга сторінка розміром із
  першу; довідник дає одне речення й посилання на першоджерело;
- **повні приклади JSON для кожного ключа** — узято рівно чотири (deny-секрети,
  статус-лайн, підпис комітів, доступність), решта лишена доксам;
- **`sandbox.credentials` / «Mask credentials» у деталях** (`tlsTerminate`, ліміт 8 MiB,
  re-signing AWS) — ключі названі рядками таблиці, механізм маскування не розписаний;
- **`policyHelper.*`, `parentSettingsBehavior`, `wslInheritsWindowsSettings`** — рядки в
  таблиці без пояснень: це адміністраторська поверхня, читач курсу її не має;
- **дев'ять керованих ключів розділу «Enterprise»** взяті лише для повноти переліку.

**Числа, які треба звіряти, а не переказувати:** `sandbox.*` — **37** ключів (у
`cross-findings.md` записано 35, докси виросли). З них **4** лише керовані, **8** свій або
керований, **26** будь-який файл. Тем — 17. Області — 5 значень.
