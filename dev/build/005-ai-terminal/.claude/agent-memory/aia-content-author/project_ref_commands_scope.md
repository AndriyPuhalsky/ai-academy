Довідник команд зібраний як **13 тематичних груп + три зрізи** (усі псевдоніми · що працює
в `-p` · приховані команди) + розділ команд термінала + гарячі клавіші + переприв'язування.
Колонок у таблицях команд рівно чотири: команда · що робить · псевдоніми й межі · у `-p`.

**Why:** групування за задачею («чим відкотити зміни»), а не за абеткою, бо до довідника
приходять із питанням, а не з літерою. Зрізи потрібні тому, що ті самі 111 рядків шукають
трьома різними способами, і дублювати їх дешевше, ніж змушувати гортати.

**How to apply:** для нового довідника цього курсу бери ту саму форму — вона вже збіглася
з `ref-hooks` і `ref-settings` (усі три: `data-own-title` на `<html>`, без `data-module`,
скрипти progress/ui/config/auth-ui/auth, статичний зміст ліворуч на Tailwind-утилітах,
широкі таблиці в `<div class="overflow-x-auto">`, бо `.table-wrap` у проєкті немає).

**Числа, перевірені наживо 2026-09-04 (Claude Code 2.1.236, macOS 26.5.2):**
111 команд (набори імен у знімку 2026-09-03 і в живих доксах ідентичні, `diff` порожній) ·
62 опції й 13 підкоманд `claude --help` · 120 рядків дій у 23 групах / 112 унікальних імен
дій / **20 контекстів** у `keybindings.md` (у `claude-code.config.json` підпис досі каже
«101 гаряча клавіша у 19 контекстах» — розходження передане кореневій сесії).

**Найцінніша знахідка методу:** діф опису кожної з 111 команд «знімок 03.09 проти живих
доксів 04.09» дав рівно одну зміну — рядок `/diff` переписали за добу. Це готова
ілюстрація тези курсу, і вона коштувала двох команд `awk`. Роби такий діф завжди, коли є
знімок і жива сторінка.

**Свідомо не влізло:** повний перелік vim-клавіш (≈60 рядків — дано перемикання режимів
і посилання) · повні таблиці 120 дій `namespace:action` · синтаксис клавіш
(модифікатори, акорди, спецклавіші) · керована служба Code Review для GitHub.
