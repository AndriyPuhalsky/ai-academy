### К1. `#navProgress` на `claude-code.html`

**Елемент** — уже в розмітці, `claude-code.html:112`, **розмітку не змінювати**:

```html
<span id="navProgress" hidden class="rounded-full border border-line px-3 py-1 font-mono text-xs text-sand"></span>
```

| Поле | Значення | Джерело |
| --- | --- | --- |
| `total` | **23** — `cfg.modules.length`, разом з іспитом `c23` (`kind:"exam"` **не** виключати) | `claude-code.config.json` |
| `doneCount` | кількість `cfg.modules`, чий `id` є в `AIAProgress.completedSet()` — саме перетин, не `completedSet().size` | `js/config.js:396–399` |
| `textContent` | рівно `"Прогрес: " + doneCount + "/" + total`, напр. `Прогрес: 7/23` | `js/config.js:339–341` |
| ключ кеша | `aia:navProgress:claude-code.config.json` | той самий, що вже пишуть сторінки уроків |
| значення кеша | **тільки довжина тексту в символах** (13–24), не сам прогрес | `js/config.js:352–356` |

**Чому `total` саме 23, а не 22.** Сторінки уроків цього ж курсу вже показують пілюлю через
`js/config.js` і рахують `cfg.modules.length` = 23. Якщо лендінг покаже `/22`, два числа в тій
самій шапці на сусідніх сторінках розійдуться. Це відповідь на «Прогрес: N/23» з п. 8 ТЗ.

**Стани — повний перелік:**

| Стан | Умова | Що видно |
| --- | --- | --- |
| Гість | немає ключа `sb-*-auth-token` у `localStorage` | пілюля `hidden`, `data-reserved` немає, дірки в шапці немає |
| Резерв | є токен **і** в кеші лежить довжина 13–24 | `data-reserved`, `visibility: hidden`, ширина тримається; тексту немає |
| Резерв протух | минуло 8000 мс, `AIAProgress.isHydrated()` = false | `data-reserved` знято, `hidden = true` |
| Гідратовано, `doneCount > 0` | після `aia:progress` | `hidden = false`, текст `Прогрес: N/23`, кеш оновлено |
| Гідратовано, `doneCount = 0` | після `aia:progress` | `hidden = true`, ключ кеша видалено |
| До гідратації, `doneCount = 0` | кеш прогресу порожній у всіх | **нічого не міняти** — інакше резерв згорнеться зарано |
| Вихід з акаунта | `js/auth.js:201` кличе `hydrate([])` → подія | пілюля ховається, кеш видаляється |
| Конфіг не приїхав | `fetch` упав | пілюля лишається схованою; `#configError` показує рендерер, як зараз |

**Де це живе:** `js/claude-code-render.js` (зона фронтендера).
`reserveNavProgress()` — **синхронно** на початку IIFE, до `fetch`; `updateNavProgress(cfg)` —
(а) у кінці `refreshProgress()` (р. 234–254, уже слухає `aia:progress`) і (б) одразу після
`renderMap()` у `.then()` після `fetch` — прогрес міг гідруватись **до** приходу конфіга,
і тоді події вже не буде.

**Резерв ширини потрібен — так.** Обґрунтування, а не смак: пілюля лежить у тій самій групі
`div.flex` шапки, що й на `index.html` / `architect.html`, де QA задачі 003/004 заміряв
розсування 300 → 439 px (+139) і внесок у CLS 0.00258 (`css/custom.css:2038–2062`). Шапка 005
ідентична, значить ідентичний і зсув. Формат ключа й атрибут — ті самі, нічого нового.

**Дублювання коду свідоме: `js/config.js` на лендінг НЕ підключати.** Він викликав би
`fillStatic` / `renderHero` / `renderSyllabus` по `[data-site]` і `[data-link]`, які на цій
сторінці вже обробляє власний рендерер (`js/claude-code-render.js:274–290`) — вийшов би
подвійний рендер і другий `aia:config-ready`. Шість функцій (`navProgressText`,
`readNavProgressChars`, `rememberNavProgress`, `forgetNavProgress`, `hasAuthToken`,
`progressHydrated`, `reserveNavProgress`, `updateNavProgress`) копіюються **дослівно** з

### К5. Д5.0 — текстовий контракт і його механічна перевірка

**Базова лінія — коміт `4dee1dd`** (єдиний коміт, у якому ці три файли зʼявились; робоче
дерево на 2026-09-05 чисте). Інструмент — `extract.py`: витягує видимий текст (без
`script`/`style`), один нормалізований фрагмент у рядок. Лежить у
`/private/tmp/claude-501/-Users-ander1-sage-Downloads-AIA-dev-build/b882c0bb-6886-475f-86b5-27c4517ddb6e/scratchpad/d50/extract.py`

(13 рядків); базові лінії **не комітити**, вони відтворюються з гіта.

Контрольні числа базової лінії: **commands 2135 · hooks 1644 · settings 1787** фрагментів
(звірено 2026-09-05: живі файли дають рівно стільки ж).

```bash
cd /Users/ander1.sage/Downloads/AIA
D=dev/build/005-ai-terminal/03-frontend/d50
for f in commands hooks settings; do
  git show 4dee1dd:claude-code-ref-$f.html > /tmp/before-$f.html
  python3 $D/extract.py /tmp/before-$f.html | sort > /tmp/before-$f.txt
  python3 $D/extract.py claude-code-ref-$f.html | sort > /tmp/after-$f.txt
  echo "== $f ==  зникло: $(diff /tmp/before-$f.txt /tmp/after-$f.txt | grep -c '^<') · зʼявилось: $(diff /tmp/before-$f.txt /tmp/after-$f.txt | grep -c '^>')"

```

**Правило (однакове для фронтендера й QA — щоб рахували однаково):**

- **«Зникло» (`^<`) мусить дорівнювати 0 в усіх трьох файлах.** Перенесення блоку — це
  переміщення, а не видалення: мультимножина фрагментів не змінюється.
- **«Зʼявилось» (`^>`) = 0 у `-ref-commands`.**
- У `-ref-hooks` і `-ref-settings` `^>` допускається **тільки** з нового бічного змісту.
  Перевірка:

```bash
awk '/<nav aria-label="Зміст довідника"/,/<\/nav>/' claude-code-ref-hooks.html > /tmp/nav.html
python3 $D/extract.py /tmp/nav.html | sort -u > /tmp/nav.txt
diff /tmp/before-hooks.txt /tmp/after-hooks.txt | grep '^>' | sed 's/^> //' | sort -u | comm -23 - /tmp/nav.txt
# очікується: порожньо
```

- Підписи прибраного `#toc` у `-ref-hooks` (р. 187–208) мусять **знайтись у бічному змісті
  дослівно** — тому вони й не потраплять у «зникло». Якщо якийсь підпис у «зниклих» — це
  порушення п. 11 («перенести, а не викинути»).
- Апостроф у будь-якому перенесеному тексті лишається `'` (U+0027) — Д5.7.

### Фронтендеру

- **Найдорожча помилка тут одна** — полагодити підкреслення через `.prose-aia a`. Це 62
  сторінки. Локальний клас, і `git diff css/custom.css` перед кожним комітом.
- **Друга за ціною** — «покращити» речення, вирівнюючи кінцівки. Форму рівняй, слова не чіпай.
  Механічна перевірка К5 ловить це за секунду — прогоняй її після кожної сторінки, а не в кінці.
- Еталон — не ідол: у нього **0 `role="region"`** на 28 прокручуваних таблицях. Д5.8.1 прямо
  дозволяє підтягнути й еталон. Це найбільша знахідка цього плану.
- `-ref-hooks` має **0 `scroll-mt`** при липкій шапці — усі його якорі зараз ведуть під шапку.
  Це полагодиться саме собою, якщо `scroll-mt-24` піде на `<section>`, як в еталона.
- Коміт після кожного пункту. Сторінки по 100–150 КБ, обрив агента незворотний.
- Сумнівний випадок (текст ламає верстку, помилка в прикладі) — **у звіт, не в правку**.
