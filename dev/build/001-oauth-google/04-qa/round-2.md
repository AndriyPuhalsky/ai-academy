## 1. CLS шапки

**Важливо про метод.** Виміряти CLS через `PerformanceObserver({type:'layout-shift'})`
цього разу було **неможливо**: вікно автоматизації тримається у фоні
(`document.visibilityState === "hidden"`), а Chrome у фоні не генерує записи `layout-shift`
взагалі. Перевірено контрольним дослідом: синтетичний зсув на 120 px не дав жодного запису.
Тому замість самого CLS міряв **джерело зсуву — геометрію**, детерміновано, через
`getBoundingClientRect()` на прихованих пробниках у тому самому CSS-контексті шапки.

### FIX-1 — скелетон слота (D-1)
| Що | Значення |
| -- | -------- |
| `aia:slotW` у localStorage | `364.84` |
| Реальна ширина контрола `#aiaAuth` | `364.84 px` |
| Ширина скелетона **з кешем** | `364.84 px` (плитки 164.84 + 109 + 67) |
| Різниця | **−0.01 px** (округлення) |
| Ширина скелетона **без кеша** (перший візит) | `300 px` → різниця **−64.84 px** |

Тобто з другого завантаження підміна скелетона на контрол не змінює бокс узагалі;
у колі 1 та сама підміна давала 439 → 468 px. Без кеша лишається рівно поведінка макета.

### FIX-2 — пілюля прогресу
| Стан | Ширина |
| ---- | ------ |
| Резерв `--navprog-ch: 13` | `119.59 px` |
| Текст «Прогрес: 5/12» (13 симв.) | `119.60 px` → різниця **−0.01 px** |
| Резерв `--navprog-ch: 14` | `126.80 px` |
| Текст «Прогрес: 12/12» (14 симв.) | `126.80 px` → різниця **0.00 px** |

**Але живим цей фікс не спостерігався.** У тестового акаунта **0 пройдених модулів**, тому
ключа `aia:navProgress:config.json` у сховищі немає — і це правильно: `rememberNavProgress()`
пише його лише при `doneCount > 0`. Пілюля в обох курсах `hidden`, зсуву не дає ні до, ні
після. Арифметику резерву перевірено на пробнику з тим самим `#navProgress[data-reserved]`.

## 2. `?code=` більше не мовчить (D-3)

Обидва сценарії довелось ганяти на `http://localhost:8000` (той самий коміт, `git status` по
`js/`, `css/`, HTML і конфігах чистий), бо превʼю-походження тримає живу сесію, а обидва
сценарії потребують **гостя**, і виходити з акаунта заборонено. Додатковий аргумент за
localhost: у залогіненому стані ця гілка коду взагалі не виконується (умова
`hadCode && !window.AIA_USER`), тож на превʼю тест був би порожнім.

| Сценарій | Очікувано | Фактично |
| -------- | --------- | -------- |
| Чиста вкладка, без кліку по Google → `/?code=SUMMER2026` | warn, **жодної панелі** | ✅ рівно один рядок `[AIA auth] повернення з ?code= не дало сесії — вхід не відбувся.`, панелей нема (`bodyHasGoogleErr: false`), URL вичищено до `/` |
| Клік «Продовжити з Google» → назад → `/?code=badcode` | warn **і** панель | ✅ той самий warn + панель «Не вдалося увійти через Google · Google не повернув причину помилки · Спробувати ще раз» |

Ознака `aia:oauth-started` після повернення `null` — спожита рівно один раз, як і задумано.
**Витоку немає:** у консолі за обидва прогони — рівно по одному повідомленню, ні `code`,
ні `state`, ні чогось схожого на токен.

Докази: `shots/R2-code-badcode-panel.jpg`.

## Створені рядки в продовій базі
**Нічого не створював.** Реєстрації, квізів, сертифікатів не було. Клік по «Продовжити з
Google» на localhost завершився редіректом на Google і назад вручну — обміну коду на сесію
не відбулось, у базі не з'явилось нічого.

## Що НЕ перевірено і чому
1. **Абсолютне число CLS** (очікувані ≈0.0214 проти 0.0234) — Chrome не рахує зсуви у
   фоновому вікні; вікно автоматизації підняти на передній план не вдалось. Замість числа —
   пряме вимірювання геометрії, яка це число породжувала (див. розділ 1).
2. **390 px** — `resize_window` на фоновому вікні не змінює viewport: `innerWidth` лишався
   `1020` за будь-якого запиту. Всі десктопні заміри зроблено при **1020 × 701**, це вище
   порога 640 px, тобто десктопна гілка. Мобільна шапка лишається на доказах кола 1;
   ризик низький — FIX-1 явно виходить при `isNarrow()`, а правило FIX-2 діє тільки на
   `[data-reserved]`.
3. **FIX-2 у живому русі** — потрібен акаунт із ≥1 пройденим модулем; проходження квізу
   пише в прод, дозволу не було.
4. Усе інше з матриці кола 1 (27 критеріїв, контраст, пастка фокуса, `verify.html`,
   `prefers-reduced-motion` тощо) свідомо не переганялось — вказівка власника.
