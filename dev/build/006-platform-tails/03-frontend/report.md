## 2. Замір `module-07`: числа, винуватець, що змінено

**Перша спроба дала хибний нуль:** для гостя `js/module.js:301` ставить `display:none` усім дітям `<main>`, крім гейта, тож `<article>` має нульову геометрію і `scrollWidth === 390`. Дефект існує лише в стані «модуль розблоковано». Відтворив тим, що робить сам код (`js/module.js:305`).

**Замір на 390 px, обхід без фільтра предків з `overflow-x`:**

| Елемент | left | width | right | scrollWidth |
| --- | --- | --- | --- | --- |
| `<table>` #0 «Стратегія / Суть / Коли брати» (`:226`) | 20 | **373.2** | **393.2** | 373 |
| ├ TH «Коли брати» | 285.7 | 107.5 | 393.2 | 108 |
| `<table>` #1 (`:386`) | 20 | 350 | 370 | 350 |
| `.diagram` #0 / #1 | 20 | 350 | 370 | вже `overflow-x: auto` |
| **`documentElement.scrollWidth`** | | | | **393** при 390 |

11 елементів «за межами» — усі з однієї таблиці. **Винуватець один:** min-content таблиці #0 = 373.2 px (122.3 + 143.4 + 107.5) при контейнері 350 px. Друга таблиця й обидві діаграми не причетні.

**Після фіксу:** 390 → `scrollWidth` **390**; 768 → 768; 1440 → 1440.
