# План: хвости після 005, роадмап, кнопка банки на AI Терміналі

## Контекст

Після релізу 005 (2026-09-05) у проді лишились платформні хвости: П-01…П-12 зі звіту QA,
хвіст 004 (цілі 20 px у футерах), «правильна відповідь = найдовша» у 390 питаннях трьох
курсів, омогліфи в `/verify`, відсутній `DEPLOY_CHECKLIST.md`, вимкнений leaked password
protection, і 26 сторінок AI Терміналу, яких не читав `aia-content-reviewer`.
Плюс два спостереження цієї сесії: `roadmap.json` показує «Зробити курси зручнішими для
всіх» як «у роботі», хоча 004 закрита 2026-09-04; `CLAUDE.md` описує вже виправлену пастку
роадмапу як живу. Плюс прохання власника: на `claude-code.html` банка monobank має бути
кнопкою «Відкрити ↗», як на `index.html`, а не сирим URL.

Робота йде на гілці `dev` конвеєром `dev/build/` (агенти правлять код і пушать у `dev`).
Мерж у `main` — лише після прямого «так» власника. Дизайн не потрібен: багфікси,
доступність, бекенд, контент і складання з наявних компонентів. Гілка зараз `dev`, дерево
чисте.

## 006 · platform-tails — що саме і де

### Зона бекендера (`js/auth.js`, `js/certificate.js`, `js/verify.js`, вміст `tg/`)

1. **П-10 бренд за курсом.** `js/certificate.js` уже отримує `courses(title, slug)`
   (`:101`). Додати мапу `slug → { brand, brandCaps, home }` (назви з `site.name` трьох
   конфігів: «AI Академія» / «AI Architect» / «AI Термінал»; лендінги `index.html` /
   `architect.html` / `claude-code.html`), фолбек — AI Академія. Підставити в медальйон
   `:156`, підпис `:196`, додаток `:286`, фолбек `:342`, посилання в `renderEmpty` `:54` і
   на картці сертифіката. Реальні значення `courses.slug` бекендер звіряє через Supabase
   MCP, не вгадує. Сторінка `/certificate` лишається під парасольковим брендом, але жодне
   її посилання не веде випускника курсу X у програму курсу Y.
2. **П-12 подвійний запит.** Діагноз QA неточний: `load()` на `DOMContentLoaded` не
   викликається (`js/certificate.js:400–403`). Причина — `aia:auth` диспатчиться двічі
   (`js/auth.js:163` і `:196`). Фікс на боці споживача: мемоїзація `load()` за
   `window.AIA_USER.id` зі скиданням при виході. `js/auth.js` тут не чіпати.
3. **П-11 розходження імені.** Не міняти ланцюжок `currentName()` (`js/auth.js:253`) —
   він годує слот шапки й діалог перед видачею сертифіката на трьох курсах. Самолікування:
   у `loadProfileName()` (`:222–244`), якщо `profiles.full_name` ≠ `user_metadata.full_name`,
   один раз за сесію best-effort `updateUser`. Помилку лишити в `console.warn`.
4. **Омогліфи `/verify`.** `js/verify.js:58`: після `trim()` — `toLowerCase()` і мапа
   кирилиця → латиниця (`а с е і о р х у ѕ ј` + великі), потім `rpc`. Якщо після
   нормалізації код змінився і сертифікат знайшовся — показати підказку «у коді були
   кириличні літери, виправили». Оцінка бекендера з 005: ~15 рядків.
5. **`tg/DEPLOY_CHECKLIST.md`.** На нього посилається `tg/GOING_LIVE.md:3,73,85`, а файла
   не було ніколи. Зміст: порядок міграцій Supabase (за `tg/CHANGELOG.md`, 002 → 005-1 →
   005-2) і smoke-сценарій (вхід, прогрес трьох курсів, квіз, сертифікат, `/verify`,
   бот `/stats`, сповіщення про реєстрацію). Підагенти не створюють `.md` — бекендер віддає
   текст фінальним повідомленням, файл пише коренева сесія.

### Кроки

1. **Скрипт `dev/build/007-quiz-distractors/check-quiz.py`** (пише коренева сесія до
   запуску агентів): таблиця по курсах — питань, «правильна = найдовша», «правильна =
   найкоротша», розподіл `answer`; `--baseline` зберігає знімок текстів правильних
   відповідей і `explain`; `--verify` доводить, що після правок правильні тексти й
   `explain` не змінилися, JSON валідний, кількість питань та сама; `--rotate` рівномірно
   переставляє варіанти й `answer` (детерміновано), попередньо `grep` на
   «перший/другий/третій/четвертий варіант» у `explain` — такі питання не крутити.
2. **Правила для агентів** (у промпті, дослівно): текст правильної відповіді не чіпати;
   подовжувати дистрактори до довжини правильної, описуючи механізм так само розгорнуто,
   але **хибно й правдоподібно** для змісту саме цього уроку; не робити дистрактор
   істинним; не додавати «всі відповіді правильні»; `q` і `explain` не чіпати; правити
   лише вміст `#quizData`; git не виконувати; після кожного файла — `python3 -m json.tool`

   `architect-01..22` → 4 × 5–6; `claude-code-01..22` → 4 × 5–6; `claude-code-23` не
   чіпати. Хвилі по 5 (ліміт токенів, як у 005). Комітить коренева сесія після кожної

4. **Ціль приймання по кожному курсу:** «правильна = найдовша» ≤ 35 % і «правильна =
   найкоротша» ≤ 35 %; жоден індекс `answer` > 40 %; `--verify` без розбіжностей.
5. **Закрити дірку в трьох місцях** (коренева сесія): `dev/build/005-ai-terminal/01-authoring/check-lessons.py:75–95`
