## Назва сторінки — це `<title>`, а не слаг

Слаги Atlassian тримають **старі** слова, а заголовки вже переписані. Якщо називати сторінку
в розділі «Джерела» так, як вона звучить у слазі (або як її назвав автор попередньої хвилі),
виходить **твердження про самі докси**, яке не збігається з живим текстом — найдорожчий клас
дефектів курсу 012.

Перевірено 2026-09-30 на довіднику-карті: з 45 цитованих сторінок **20 назв розійшлись**.

```bash
curl -sL "$URL" | python3 -c 'import sys,re,html;print(html.unescape(re.search(r"<title>(.*?)</title>",sys.stdin.read(),re.S).group(1)))'
```

Приклади (ліворуч — як писали в курсі, праворуч — живий `<title>` на 2026-09-30):

| Зі слага / зі звітів | Насправді |
| --- | --- |
| …in team-managed **projects** | …in team-managed **spaces** (систематично, ~8 сторінок) |
| Create, edit, and delete transitions… | **Manage work item transitions in team-managed spaces** |
| Customize **a work item's** fields… | Customize **work item** fields… |
| Manage **shared** dashboards | **Manage dashboards** |
| Export your Jira Cloud site's data | **Export data from Jira Cloud** |
| **Rovo usage limits** | **How Rovo credits work** |
| Update a **product** URL | Update an **app** URL **subdomain** |
| About the portal and help center | **What is a portal?** |
| Automatically clone a work item when it's done | **Schedule work items to recur using automations** |
| How is **my** usage calculated? | How is **your automation** usage calculated |
| Permissions limitations in **free** Jira sites | …in **Free** Jira sites (регістр) |

⚠ Окремо: назва в `<title>` і напис-посилання на екрані теж можуть різнитись. На сторінці
`Usage` глобальної автоматизації стоїть посилання **«How is my usage calculated?»** — тобто
екранний напис лишився старим, а заголовок сторінки вже новий. Обидва правильні, але
атрибутувати треба той, який цитуєш.

## KB чи продуктові докси — лише за адресою

`learningResourceType` у JSON-LD дорівнює `"Knowledge base article"` **на всіх** сторінках
`support.atlassian.com`, включно з `/docs/`. Тому мітка ні про що не свідчить: «стаття бази
знань» = у шляху стоїть **`/kb/`**. Банер платформи («Platform Notice: Cloud Only») і позначку
«generated by AI» дивитись окремо.

**Why:** курс 012 стоїть на формулі «стаття бази знань розходиться з екраном і продуктовою
довідкою», і без правильної атрибуції вона перетворюється на «докси суперечать доксам».

**How to apply:** перед здачею прогнати всі назви сторінок зі свого розділу «Джерела» через
`<title>`; у звіт покласти список розбіжностей. Пов'язане: [[atlassian-docs-fetch]],
[[docs-scope-articlebody]], [[reference-atlassian-docs-lookup]],
[[reference-jira-plan-limits-sources]].
