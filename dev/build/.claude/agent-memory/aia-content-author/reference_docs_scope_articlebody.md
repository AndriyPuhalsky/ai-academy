Два прийоми для випадку, коли доводиш **відсутність** твердження, а не наявність.

## 1. «Сторінка цього не каже» доводиться по `articleBody`, не по HTML

Сторінки `support.atlassian.com` несуть у собі JSON-LD (`<script type="application/ld+json">`)
з полем **`articleBody`** — усім текстом статті одним рядком. Це найдешевший спосіб отримати
рівно тіло статті, без бічного меню, футера й маркетингових блоків.

```python
m = re.search(r'"articleBody":"(.*?)","(?:[a-zA-Z]+)":', html, re.S)
body = m.group(1).encode().decode('unicode_escape')   # ⚠ &#x27; лишається сутністю
```

**Перевірено 2026-09-30 (хвиля 10, j02 / j05):** треба було довести, що продуктова довідка
про архівацію роботи **не має** обмеження за планом.
`jira-software-cloud/docs/archive-an-issue/` — голий `grep` по HTML дає `Premium` ×2 і
`Enterprise` ×1 (це меню й перехресні посилання), а в `articleBody` **немає ні `Premium`, ні
`Enterprise`, ні `Free` взагалі**. Без цього прийому висновок був би прямо протилежний.

⚠ У тому ж JSON-LD лежить `learningResourceType`, і він не завжди збігається з адресою:
`cloud-automation/docs/automation-service-limits/` (шлях `…/docs/…`, позначки «generated by AI»
немає) підписана `"learningResourceType":"Knowledge base article"`. Тобто «docs проти KB» за
адресою визначається не завжди — дивитись і на банер сторінки.

## 2. Довгі цитати в `screens/*.md` — звіряти після нормалізації

Знімки sandbox (`00-research/screens/NN-….md`) переносять довгі написи через кілька рядків і
обертають їх у `**…**`. Тому `quote in screens_text` на цитаті довше ~60 знаків дає **хибний
MISS**, хоч напис там є дослівно. Нормалізувати перед звіркою:

```python
n = re.sub(r'\s+', ' ', re.sub(r'\*\*', '', screens_text))
```

2026-09-30 так «не знайшлись» дві з дванадцяти цитат (`Space keys must start with an uppercase
letter…`, `Changing the space key will re-index your space…`) — обидві були на місці.

**Why:** курс 012 стоїть на формулах «стаття бази знань розходиться з екраном і продуктовою
довідкою» та «напису, якого немає в знімку, не вигадувати» — обидві вимагають доводити
відсутність, а саме тут звичайний `grep` бреше в обидва боки.

**How to apply:** перед тим як написати «у довідці такого обмеження немає» або «цього напису в
знімку немає» — прогнати обидві нормалізації; результат із датою прочитання класти у звіт.
