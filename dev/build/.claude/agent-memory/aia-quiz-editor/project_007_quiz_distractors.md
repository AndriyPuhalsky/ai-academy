Задача 007 `quiz-distractors` (заведена 2026-09-06): у 88,7 % питань трьох курсів правильна
відповідь була найдовшим варіантом, тому тест проходився без читання уроку. Редактор
переписує **лише дистрактори** в `#quizData`; індекс `answer` вирівнює скрипт `--rotate`
кореневої сесії **після** редактора.

**Why:** квіз на сервер не йде (`js/progress.js` шле фіксований бал), тож єдиний захист від
«вгадування за довжиною» — сам текст варіантів; правдоподібність дистрактора важить стільки
ж, скільки його хибність.

**How to apply:** робоча нарізка, яка дала рівно 28,6 % / 28,6 % на партії A3 (`architect-13`
… `architect-17`, 7 питань у файлі) — на кожен файл 2 питання «правильна найдовша»,
2 «найкоротша», 3 «середина», нічиїх нуль. Спершу проєктуєш цільову довжину кожного
дистрактора, потім міряєш `len()` і підганяєш: різниця в 1–2 символи з правильною =
ризик нічиї, тримати запас ≥ 3 символи. Перевірка після кожного файла —
`dev/build/007-quiz-distractors/check-quiz.py --files … --verify …/baseline.json`.
Див. [[reference-quizdata-roundtrip]].
