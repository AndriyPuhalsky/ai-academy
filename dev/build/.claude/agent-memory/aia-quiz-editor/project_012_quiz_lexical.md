Курс 012 «Jira з нуля» (уроки `modules/jira-01…22`, іспит `jira-23`) до цього проходу вже мав
вирівняні довжини (правильна = найдовша 7 зі 158) і 0 пунктуаційних маркерів. Лишились **маркери
словом**; їх розбили на три партії (А: 02, 04, 06, 07, 08 · Б: 10, 11, 12, 16, 18 · В: 19, 21,
22, 23-іспит), по одному редактору на партію, усі троє працюють паралельно в одному дереві.

**Why:** квіз проходився без читання уроку, і після закриття довжини лишалась остання поверхова
підказка — слово. Власник тримає курс **лише на безкоштовному плані Jira**, тому факт у
дистракторі має бути з тексту свого уроку, а не з памʼяті моделі.

**How to apply:** партія А закрита 2026-09-30 (6 маркерів → 0, 7 правок дистракторів, звіт —
`dev/build/012-jira/01-authoring/reports/quiz-lex-a.md`). Робочий цикл, який тут спрацював:
зліпок уроку через `01-authoring/dump-lessons.py --out <скретчпад> --upto N` (HTML уроку 60–70 КБ
тексту — читати цілком дорого, у зліпку в кінці вже лежить квіз із ✓) → чернетки в JSON-спеці →
**вимірювач без запису** (довжини, роль правильної, нічиї, обидва боки маркерів) → точкова
заміна рядка → чотири перевірки на файл (`json ok`, `check-quiz.py`, `--verify <baseline>`,
`check-quiz-markers.py --lexical`), плюс `check-lessons.py --pattern` наостанок.

Ґрунт для дистрактора шукати не лише в блоці 3 свого уроку: у 012 половина опор лежала в
`explain` самого питання (він часто **дослівно** заперечує дистрактор: «обмеження „фільтр живе
в одному спейсі“ не існує») і в сусідніх уроках (майстер створення спейсу — урок 3, вигляд
`Summary` — урок 6). Git не виконувати: комітить коренева сесія після хвилі.
