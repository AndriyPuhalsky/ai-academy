Задача 007 прибирає підказку «правильна відповідь — найдовша» у 57 уроках; кожен агент
дістає партію з 5–6 файлів і переписує **лише дистрактори**.

**Why:** тест проходився без читання уроку (AI Architect — 133/136 питань), а квіз на сервер
не йде взагалі, тож правдоподібність дистрактора важить стільки ж, скільки його хибність.

**How to apply:**
- `check-quiz.py` рахує «найдовша»/«найкоротша» лише за **унікальним** максимумом/мінімумом:
  нічия за довжиною зникає з обох колонок, але світиться в «+нічиї» — тому нічиї треба
  прибирати явно, а не радіти нулю в колонці «найдовша».
- Цілитись не в нуль, а в природний розкид: ~20 % «найдовша» і ~20 % «найкоротша» по партії.
  Нуль у колонці «найкоротша» — така сама закономірність, як 100 % у «найдовша»; у партії A2
  довелось робити другий прохід, щоб її створити.
- Довжина правильної диктує стиль: де правильна терсова (`Твій код` — 8 символів,
  `response.content[0].text` — 24), дистрактори теж мають лишатись терсовими, інакше
  новий сигнал — «розгорнутий варіант правильний».
- Робочий прийом подовження: дати дистрактору **власний хибний механізм** з лексикою уроку
  (`max_tokens`, `stop_reason`, `.gitignore`, префіл, ембедінг), а не води. Перевірка —
  чи спростовує його наявний `explain`.
- Індекси `answer` не чіпати: розкид робить `--rotate` після агентів. Див.
  [[scratchpad-collision-parallel-agents]].
