Крім довжини (`check-quiz.py`, задача 007) і пунктуації, правильну відповідь видає **слово**.
`dev/build/012-jira/01-authoring/check-quiz-markers.py` міряє це у два боки для кожного питання:
`--lexical` додає слова `бо`, `тому`, `лише`, `завжди` до набору знаків `— : ; → «`.

- **Слово лише в правильному** → додати його **в один дистрактор**: «тому/бо» — через хибну
  причину, «лише/завжди» — через хибне обмеження. Найдешевший прийом: у дистракторі, де вже є
  «і», замінити сполучник на «тому» (`…читають дані лише зі спейсу, і список порожній` →
  `…, тому список порожній`) — зміна на 3 знаки, маркер закритий.
- **Слово в усіх дистракторах, а в правильній немає** → переписати один дистрактор без слова.
  ⚠ Ловиться **ціле слово без огляду на сенс**: займенник «призначені тому, хто дивиться»
  чекеру такий самий маркер, як сполучник «тому». Лікується перефразуванням («призначені тій
  людині, яка його відкрила») — сенс і довжина лишаються ті самі.

**Часто маркер стоїть у цитаті, а не в стилі.** «Сайт, який **завжди** був на безкоштовному
плані» = «has always been on a Free plan»; «між великою справою і підзадачею **завжди** мусить
стояти задача» — фраза з тексту уроку. Такий маркер з боку правильної не лікується взагалі
(її текст недоторканний) — тільки з боку дистрактора. Це нормальний і єдиний шлях.

**Пастка симетрії:** прибираючи слово з дистрактора, перевір, чи не створюєш маркер в інший бік
(і те саме з пунктуацією: викинув «—» з єдиного дистрактора, у якого воно було, — і «—» лишилось
лише в правильній). Тому після кожної правки — обидва прогони чекера: з `--lexical` і без.
