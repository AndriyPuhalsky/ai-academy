Під час партії A2 задачі 007 файл `scratchpad/apply.py`, який я щойно написав, був підмінений
іншою реалізацією (паралельно працювали три інші партії 007 і фронтендер). Запуск упав на
чужому форматі аргументів.

**Why:** кілька агентів у одній хвилі можуть писати службові скрипти з очевидними іменами
(`apply.py`, `dump.py`), і хто останній — того й файл.

**How to apply:** називати службові скрипти з префіксом партії (`a2-apply.py`), а після
будь-якого несподіваного падіння скрипта спершу перевіряти `git diff` цільового файла —
чи не встиг він щось записати до помилки. У A2 файл лишився недоторканим, але це треба
було довести, а не припустити.
