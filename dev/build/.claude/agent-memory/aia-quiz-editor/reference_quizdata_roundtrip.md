Два технічні факти, перевірені на партії A3 задачі 007 (2026-09-06):

1. **Формат `#quizData` відтворюваний.** Для `modules/architect-*.html` вміст блока
   побайтово дорівнює `json.dumps(data, indent=2, ensure_ascii=False)` з дописаними
   6 пробілами до кожного непорожнього рядка. Тому безпечний спосіб правки —
   parse → змінити `options[i]` → серіалізувати назад: діф покаже лише змінені рядки,
   решта сторінки не зсувається (кількість рядків у файлі лишається тою самою).
   Перед записом варто перевірити round-trip на незміненому файлі — якщо не збігається
   побайтово, формат блока інший і треба правити порядково.

2. **Скретчпад сесії ділиться з паралельними агентами тієї ж хвилі.** Файл
   `scratchpad/apply.py`, створений цією сесією, був перезаписаний іншим агентом 007
   під час роботи. Давати службовим скриптам унікальні імена (`apply_a3.py`, `e13.json`)
   і не покладатись на те, що записане лишиться незмінним.
