**Дві речі зі стенда 011, які варто мати під рукою.**

**1 · `opacity: 0` прибирає CLS, нічого не полагодивши.** На `/roadmap` додавання
`data-page-in` давало CLS **0,0119 → 0**: зсув `svg#trail` нікуди не дівався, він просто
відбувався, поки шар невидимий, і браузер не зараховував його в метрику. Доказ — прогін під
`prefers-reduced-motion`: M1 не грає, і 0,0116 повертається. Тобто «покращення CLS» від
будь-якої появи через прозорість треба перевіряти прогоном під reduce, інакше приймається
маскування замість фікса. У проєкті вже була парна пастка (010: чесний резерв висоти
ПОГІРШИВ CLS).

**2 · A/B «а якби тут стояв цей атрибут» — без правки файла.** Ставити атрибут через
`Page.addScriptToEvaluateOnNewDocument` під час парсингу: `setInterval` 1 мс, який чекає на
`document.querySelector('main#main')` і одразу себе гасить. Спрацьовує раніше за
`js/motion.js` (той чекає `DOMContentLoaded`), тож вимірюється справжня поведінка, а
робоче дерево лишається чистим. Там само реєструвати слухачі подій сторінки: для події на
самому `document` порядок **реєстрації** важливіший за фазу, тож слухач із document_start
спрацьовує раніше за слухач самої сторінки — це дає зняти стан рівно в мить її події.

Клієнт CDP і рецепт запуску Chrome — `dev/build/011-open-tails/stand/cdp.mjs` і `README.md`
(кеш вимикати завжди, інакше Chrome віддає старий `js/motion.js` і варіант B виглядає як A).
