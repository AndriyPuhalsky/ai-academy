У дизайн-конвеєрі `dev/design/NNN-slug/` **остаточне джерело коду для перенесення —
`04-variants/shared/` (base.js, base.css, tokens.css) + `04-variants/variant-<обраний>/`.**
Папка `03-build/` (агент №3) — **застаріла й не переноситься**.

**Why:** агент №4 (валідатор) за правилом конвеєра **не змінює `03-build/` ні на байт** —
усі його виправлення живуть окремо, у `04-variants/shared/`, позначені `FIX-N`. У задачі
001 це були 12 правок, серед них **дві блокуючі** (модалка недосяжна на 320×560; фокус
потрапляє на невидиме поле — WCAG рівня A). Плюс `03-build/NOTES.md` містив шість
фактично неточних тверджень, перелічених у `04-variants/verdict.md`.

**How to apply:** у кожному плані, де є дизайн, писати явно й таблицею — який файл і які
рядки є джерелом розмітки, CSS, токенів і текстів. Фронтендер не має гадати. Окремо
перелічувати, чого зі `shared/` **не** переносити: секції риштування, репліку сайту,
CSS невибраних варіантів.

**Три речі, які макет із пісочниці систематично не може знати** (перевіряти в кожній
такій задачі):
1. `position: absolute` на підложці → на сайті має бути `fixed` (у пісочниці вона живе
   всередині сцени);
2. `@container page (...)` → на сайті контейнера немає, правила мовчки не спрацюють;
   треба переводити на `@media`;
3. діалоги монтуються в `stage` → на сайті в `document.body`.
