Сертифікат (`js/certificate.js`, підключений рівно з одного місця — `certificate.html`,
спільний для всіх трьох курсів) можна перевірити **повністю, не створивши жодного рядка
в проді й не логінячись**.

**Стенд, який працює:**
1. Локальний сервер із кореня репозиторію (порт **не 8000** — QA займає; 8765 підходить),
   з `Cache-Control: no-store`. Без цього Chrome віддає стару версію `js/*` після правки,
   і фікс «не працює» на порожньому місці. Виправляється `fetch(url, {cache:'reload'})`
   перед перезавантаженням.
2. У консолі сторінки підмінити `window.AIA_USER` і `window.sb` заглушкою: обʼєкт із
   `select/eq/order`, що повертають себе, і `then`, що віддає `{data, error:null}`.
   `load()` перемальовується по `document.dispatchEvent(new CustomEvent("aia:auth"))`.
   Далі — **справжній клік по справжній кнопці**, тобто реальний шлях коду.
3. `window.alert` замінити на запис у змінну: діалог блокує браузерний екстеншен намертво.
4. Обгорнути `window.jspdf.jsPDF` так, щоб `doc.save` віддавав `doc.output("blob")`
   POST-ом на локальний сервер, а не в теку завантажень.

**Доказ, що стенд міряє те саме, що прод:** до правки харнес дав рівно
**28 537 699 Б** — байт-у-байт розмір справжнього сертифіката, заміряний QA.

**Перевірка результату — трьома незалежними шляхами:**
- байти: `grep -a -o "/URI"` тощо просто по файлу PDF (jsPDF не стискає словники сторінок);
- вміст сторінок: JPEG-потоки витягуються з PDF пошуком `ffd8ff`…`ffd9` і читаються як
  звичайні картинки (`Read` показує їх) — це надійніше за будь-який скриншот;
- посилання: **pdf.js** (cdnjs, `pdf.min.js` + `workerSrc`) → `page.getAnnotations()`
  віддає `subtype: "Link"` і розібраний `url`. Це той самий рушій, яким переглядачі
  будують клікабельний шар, тож його висновок і є відповіддю «чи буде клікатись».

**Чого робити не варто:** вбудований переглядач PDF у Chrome **не годиться** для
екстеншена — знімок екрана плагіна не оновлюється після скролу/зуму (повертається той
самий кадр), тому клікати доводиться наосліп. Три спроби, далі зупинитись і передати
клік тестувальнику-людині.
