# CLS від підміни шрифту: 0,195 на `/claude-code-ref-settings` @1280

Заміряно 2026-09-10 (011, QA коло 2, власний Chrome по CDP, **кеш вимкнено**, по 3 прогони).

**Факт.** `/claude-code-ref-settings` @1280 дає **CLS 0,1948** — це **поза порогом 0,1** і
найбільше число, знайдене на сайті (для порівняння: найгірше в колі 1 було 0,0477 на
`/roadmap` @768). Число стабільне: 3 з 3 прогонів на превʼю, 3 з 3 на локальному дереві
**до** фікса `d7ec232` і 3 з 3 після — тобто до хвилі 2 воно стосунку не має.

**Why:** причина доведена A/B-блокуванням через `Network.setBlockedURLs`:

| Що заблоковано | CLS |
| -------------- | --- |
| нічого | 0,1948 · 0,1948 |
| `cdn.tailwindcss.com` | 0,1588 · 0,0815 |
| **`fonts.googleapis.com` + `fonts.gstatic.com`** | **0 · 0** |

Тобто винен **font swap** (`display=swap` у єдиному `<link>` на три сімейства:
Prata + Golos Text + JetBrains Mono). Зсув один, у момент FCP (t = 339 при FCP 304),
джерела — `DIV.ds-note > P` і `LI.pl-3.text-fg-2`: переливається весь текстовий стовпець.

**How to apply:**
- **Сторінко- і ширино-специфічно, не загальний дефект.** @1280: `ref-hooks` 0,0625,
  `ref-commands` 0,0020, лендінг `claude-code` 0,0019. Та сама `ref-settings`: @1024 —
  0,0220, @768 — 0,0124, @390 — **0**. Отже мірити треба саме пару «сторінка × ширина»,
  а не «сайт».
- Міряти з **вимкненим кешем** — це сценарій першого візиту, той самий, що потрапляє в
  CrUX. З теплим кешем шрифт уже є й зсуву не буде.
- Кандидати на лікування (не рішення QA): `size-adjust` / локальний `@font-face` для
  запасного шрифту, або `font-display: optional` на заголовковий Prata.
- Задача не заведена — це рішення власника; число подане в реєстр хвостів 011.

Метод — [[method-cdp-own-chrome]]; A/B причини — [[method-independent-refutation]].
Не плутати з [[project-cc-landing-cls]]: там причина інша (порожні елементи без резерву).
