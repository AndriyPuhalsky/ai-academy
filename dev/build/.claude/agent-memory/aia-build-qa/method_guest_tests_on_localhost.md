Власник лишає в браузері **живу сесію тестового акаунта** на dev-превʼю, бо екран
`accounts.google.com` розширенню закритий і повторно увійти я не зможу. Виходити з акаунта
заборонено.

**Правило:** усе, що вимагає стану «гість» (модалка входу, панелі помилок OAuth, вигляд
слота гостя, гілки коду під `!window.AIA_USER`), ганяти на `http://localhost:8000`
(`python3 -m http.server 8000` з кореня). Це **інший origin**, тому власний `localStorage`
і власна сесія — превʼю не зачіпається взагалі. Код той самий, якщо `git status` по
`js/`, `css/`, HTML і конфігах чистий; це і треба перевірити першим ділом і написати у звіті.

Приватне вікно для цього не потрібне (і розширення туди, схоже, не ходить).

Дві деталі, знайдені в колі 2 задачі 001:
- `sessionStorage`-ознаки (`aia:oauth-started`) живуть **у вкладці**, тому «клік по Google →
  повернення» треба робити тією самою вкладкою. Після кліку вкладка опиняється на
  `accounts.google.com`, і перший `navigate` звідти падає з «Navigation to this domain is not
  allowed» — **повторний виклик тієї ж навігації проходить**. Не здаватись з першого разу.
- Не йти на прод (`ai-academia.com.ua`) по гостьовий стан: там код гілки `main`, тобто без
  фіксів, — тест буде про інше.
