# Пікселі знімка як доказ: смуга прокрутки, кільце фокуса, повзунок

Заведено 2026-09-10 (011, QA хвилі 2). **Why:** є речі, яких DOM не знає взагалі —
`::-webkit-scrollbar`, `::selection`, кільце фокуса під маскою, вміст, який гасить
`mask-image`. `getComputedStyle` на псевдоелементі смуги нічого не повертає, тож
«повзунок видно» доводиться **тільки** пікселями. У цьому колі саме так знайдено
дефект D-01 (маска §41 стирає вертикальний повзунок) і доведено, що горизонтальний цілий.

**How to apply:**

## 1. Знімок вузької смужки

```js
await P.s("Page.captureScreenshot", { format: "png",
  clip: { x, y, width, height, scale: 1 } });
```

⛔ **Пастка, яка коштувала трьох марних прогонів:** `clip` рахується **від початку
документа**, а не від вʼюпорта. `getBoundingClientRect()` дає координати вʼюпорта, тому
без `+ window.scrollX / scrollY` знімок виходить із зовсім іншого місця — і суцільно
темна смужка читається як «правки не доїхали». Завжди:

```js
{ px: r.left + window.scrollX, py: r.top + window.scrollY }
```

`deviceScaleFactor: 1` (він і так такий після `Emulation.setDeviceMetricsOverride`)
означає 1 CSS-піксель = 1 піксель зображення — арифметика прямо збігається.

## 2. Читач PNG без залежностей

`04-qa/stand/png.py` — ~40 рядків: `zlib.decompress(IDAT)` + розфільтрування пʼяти
типів рядка. Ніякого PIL, ніякого `npm i`. Далі рахуємо яскравість
`0.2126R + 0.7152G + 0.0722B` і шукаємо сегменти «світлого».

## 3. Що саме доводити

| Питання | Як прочитати |
| ------- | ------------ |
| смуга є? | найсвітліший піксель у смузі 12 px під блоком; порог ~90 відсікає текст і рамки |
| повзунок рухається? | межі світлого сегмента при `scrollLeft` 0 / max: 5…515 → 155…666 |
| маска не гасить? | яскравість **уздовж** повзунка: 109 рівно скрізь, крім 1 px згладжування |
| кільце фокуса ціле? | верхній і нижній рядки кільця по всій ширині + ліва/права колонки |
| колір той? | RGB прямо з пікселя → контраст рахувати проти **виміряного** фону, не проти токена |

## 4. Обовʼязковий контроль

Знімок «після» сам по собі нічого не доводить. Пара «маска увімкнена / `mask-image: none`
через інжектований `<style>`» — доводить (див. [[method-ab-css-proof]]). У D-01 різниця
була: жодного пікселя > 96 проти чотирьох колонок по 109.

## 5. Кільце фокуса в цьому проєкті — `box-shadow`, а не `outline`

`components.css:53` ставить `outline: none` і подвійне кільце `box-shadow`. Тому
перевірка `getComputedStyle(el).outlineStyle` дає `none` **навіть коли фокус видимий**
і читається як «кільця немає». Дивитись треба `boxShadow` — і краще пікселями.
Крім того, `.focus()` із коду не вмикає `:focus-visible`: потрібен справжній
`Input.dispatchKeyEvent` Tab (сфокусувати попередній у порядку елемент і натиснути Tab —
швидше, ніж тиснути Tab 30 разів від початку сторінки).
