# Прохід курсу за входом: 23 уроки без розорення на знімках

Перевірено 2026-10-01 (012, коло 2, j01 → j23 + сертифікат).

**Why:** прохід робиться в **браузері власника** (єдине місце з живою сесією), а там
кожен крок — окремий виклик інструмента. «Знімок → знайти кнопку → клік» на 23 уроках
коштує сотні викликів. При цьому сам прохід — єдиний спосіб закрити К48/К49/К52/К53.

**How to apply:**

- **Пакетувати:** `browser_batch` із парами `navigate` + `javascript_exec` — по 3–4 уроки
  на виклик. Один виклик = один урок у ~700 токенів виводу.
- **Квіз проходити з `#quizData`:** `js/quiz.js` тасує і питання, і варіанти, тому
  зіставляти треба **за текстом питання**, а не за індексом, і клікати справжню
  `.ds-quiz__opt`, чий текст містить `options[answer]`.
- **Кнопку «Позначити завершеним» на проміжних уроках** тиснути `#completeBtn.click()`:
  той самий слухач, той самий `submit_quiz`, різниця лише в `isTrusted`, якого код не
  питає. **Справжній клік миші лишати для ключових точок** (перший урок, модалка імені) —
  і писати у звіті, де який спосіб.
- **Координати перераховувати перед КОЖНИМ кліком:** вікно власника міняє розмір посеред
  роботи (у 012 кадр знімка їхав 1568 → 1440 px). Формула — `coord = css × (кадр / innerWidth)`;
  `document.elementFromPoint` перед кліком підтверджує, що під точкою справді кнопка.
  ⚠ Клік по `ref` з `find` одного разу «пройшов» без жодного ефекту — координати надійніші.
- **«Запит не пішов» доводиться тільки з позитивним контролем.** `read_network_requests`
  починає писати з першого виклику, тож порожній результат сам по собі нічого не означає.
  Схема: `clear: true` → скасувати діалог → прочитати (порожньо) → підтвердити → прочитати
  (рівно один `POST …/rpc/submit_quiz` 200). Поява другого запиту доводить, що панель
  писала й під час першого.
- **Гейти на проході:** прогрес чекати умовою `AIAProgress.isHydrated()`, а не таймаутом.
  Лічильник сайдбара (`.ds-snav__count`) і кількість `[aria-disabled="true"]` у сайдбарі
  дають готову пару «пройдено / замкнено» — −1 замок на кожен урок, без жодного знімка.
