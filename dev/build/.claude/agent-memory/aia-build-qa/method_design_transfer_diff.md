# «Відповідність макету» доводиться diff-ом правил, а не оком

Заведено 2026-10-01 (012, коло 1), коли фокусом власника була саме відповідність макету.
**Why:** знімок «макет ↔ превʼю» ловить грубу розбіжність, але мовчить про втрачене
правило в стані, якого немає на знімку (`:focus-visible`, `@media`, `[data-cat="done"]`).
А їх у компоненті «вікно» 143 штуки на 1 319 рядків.

**How to apply.** Нормалізувати обидва файли (зняти коментарі, схлопнути пробіли),
розібрати на пари `селектор → відсортований кортеж декларацій` і порівняти три множини:
втрачені селектори · зайві · ті, що є в обох, але з різним тілом.

```python
def norm(s): s = re.sub(r'/\*.*?\*/', '', s, flags=re.S); return re.sub(r'\s+',' ',s).strip()
def decls(s):
    d = defaultdict(set)
    for m in re.finditer(r'([^{}]+)\{([^{}]*)\}', s):
        d[m.group(1).strip()].add(tuple(sorted(x.strip() for x in m.group(2).split(';') if x.strip())))
    return d
```

⛔ **Пастка, яка дала хибну тривогу в 012:** звичайний `dict` замість `defaultdict(set)`
залишає **останнє** входження селектора. `:root` і `.win` оголошені по кілька разів
(базове значення + перевизначення в `@media`), тож словник показав «`--win-col-w`
розходиться: 160 px у макеті проти 132 px у коді» — а насправді обидва значення є
в обох файлах, просто друге лежить у `@media (max-width: …)`. Завжди мультимапа.

Друга пастка: зріз файла «від заголовка секції» починається **посеред коментаря**, тому
подальше зняття коментарів не спрацьовує для першого з них — у список «сторонніх класів»
попадають слова з коментаря (`.css`, `.term`). Різати від `rfind('/*', 0, i)`.

**Що дав метод у 012 за один виклик:** компонент `win` — 0 втрачених селекторів,
0 правил із різним тілом, 1 зайвий (той, якого вимагав план); `js/jira-motion.js` —
побайтово ідентичний; `css/jira.css` поза свідомо переписаними секціями — 0 розбіжностей.
Це дорожче за будь-який знімок, бо дозволяє сказати «перенесення точне» з доказом.

**Доповнення знімками все одно потрібне** — для того, чого в CSS немає: порядок секцій,
обчислені токени (`getComputedStyle(documentElement)` по списку імен), геометрія hero,
агреговані сигнатури компонента на всіх його екземплярах (у 012: 131 вікно → рівно одна
пара «фон вікна / фон шапки» і рівно три сигнатури канта за категорією статусу).
