Автор уроку читає розділ доксів «Authenticate from the command line», бачить там
`--callback-port`, `--client-id`, `--client-secret` — і пише «є ще прапорці для входу».
Але докси в тому ж розділі показують їх у прикладі з **`claude mcp add`**: вони задаються,
**коли сервер додають**, а не коли в нього входять. Живий `claude mcp login --help`
(2.1.263) має рівно два рядки: `-h, --help` і `--no-browser`.

Читач, який виконає таке речення буквально, отримає `unknown option`.

**Як перевіряти (30 секунд, читально):** для кожного прапорця, названого в тексті поруч із
командою, запустити `claude <підкоманда> --help` і знайти його в списку `Options:`. Немає —
шукати, у якої підкоманди він є (`claude mcp add --help`, `add-json --help`), і виправляти
адресу, а не викидати факт.

Той самий прийом ловить зворотне: прапорець із доксів, якого в збірці немає взагалі
(див. [[course-numbers-drift]] про прапорці-привиди).

Це **виправна** зона редактора: джерело знайдене й воно суперечить тексту — правимо й
показуємо джерело у звіті (див. [[lesson-verification]]).
