Два дешеві способи відрізнити «факт не підтверджується» від «інструмент не побачив», обидва
без акаунта й без браузера (перевірені на рецензії `j22`, 2026-09-19).

**1. Жива адреса сервера (MCP, API).** `curl -s -D - -o /dev/null <url>`:
- **401 + `www-authenticate: Bearer resource_metadata=…`** = адреса жива й захищена входом;
- **404** = такого шляху немає.
Так за секунду перевіряється твердження уроку «ми зверталися за адресою — сервер відповів
відмовою». На `https://mcp.atlassian.com/v2/mcp` і `…/v1/mcp/authv2` **обидві** адреси дають 401
(стара не падає гучно) — тобто «одна правильна, друга ні» було б хибним висновком.

**2. Порожня сторінка ≠ сторінки немає.** `atlassian.com/certification` редіректить на
`community.atlassian.com/learning/hub/certifications`, і `curl` віддає **32 символи тексту** —
вміст малює браузер. Ознака: 200 + великий HTML + мізерний текст після зняття тегів. Висновок
для звіту — «цитувати нічого, потрібен знімок у браузері», а не «сторінки не існує».

**How to apply:** перед тим як записати факт у «непідтверджені», прогнати ці дві перевірки й
показати у звіті сам вивід (код, заголовок, довжину тексту). Обидва прийоми — читання, дозволені
завжди; заборонені лише команди, що змінюють конфігурацію (`claude mcp add/remove/login`, `list`).
