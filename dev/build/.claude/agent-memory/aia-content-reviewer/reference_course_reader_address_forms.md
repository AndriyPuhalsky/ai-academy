Тексти лендінгів і більшість уроків звертаються до читача **парними формами**: `бачив(ла)`,
`чув(ла)`, `готовий(а)`, `клацнув(ла)`. Аудиторія 012 названа прямо — «маркетолог, бухгалтер,
HR, власниця кав'ярні», тож урок, написаний лише в чоловічому роді, половину читачів виштовхує
на першому ж реченні.

**Як ловити (одним python-проходом по тексту без тегів):**
```python
масc = re.findall(r'\bти (вже )?(бачив|заходив|створив|завів|зробив|відкрив|поставив)\b', t)
парн = re.findall(r'\(ла\)|\(а\)', t)
```
Багато `масc` при майже нульових `парн` — дефект. У j11 було 5 проти 0 (парні форми траплялись
лише у варіанті поля «Сам(а) написав(ла)», тобто в даних, а не в наррації), тоді як j04/j05/j06/j12
дають 5–16 парних форм.

**Це зона рецензента:** чиста правка формулювання, факт не міняється, ризику нуль.
Перевіряти разом із рештою проходу «по словах» — див. [[lesson-verification]].
