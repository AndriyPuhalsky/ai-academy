Задача 008 `terminal-content-review`: `aia-content-reviewer` читає по одній сторінці курсу
«AI Термінал» (26 сторінок), правлячи лише формулювання у своєму файлі.

**Why:** до 2026-09-05 редактор не читав жодної з 26 сторінок — це відкритий хвіст 005.
Одразу перед 008 задача 007 вирівняла дистрактори квізів у всіх трьох курсах.

**How to apply:**
- **`<script id="quizData">` не редагувати.** Будь-яка правка ламає
  `python3 dev/build/007-quiz-distractors/check-quiz.py --verify dev/build/007-quiz-distractors/baseline.json`
  (він звіряє тексти правильних відповідей, `q`, `explain` і кількість питань). Зауваження до квіза — у звіт.
- Механіку рахує `python3 dev/build/005-ai-terminal/01-authoring/check-lessons.py` — він
  проходить **усі 23 уроки**, не лише переданий файл, тож порівнюй свій рядок до і після правок.
- Стійкий шум чекера: заборонене слово «просто» всередині варіанта квіза (c03, c04, c06, c08,
  c12, c16, c17). Прибрати його редактор не може — воно в недоторканному блоці.
- Перед фінальним повідомленням: `git diff --stat` по своєму файлу (без `Bin`), git-команд не виконувати.
