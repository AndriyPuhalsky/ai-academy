# Реєстр незакритих тверджень без джерела

**Що сталося.** У курсі 012 «Jira з нуля» дефект j02 («одинадцяту людину Jira додати не
дасть») прожив три дні й пʼять хвиль. Рецензент j02 ще 2026-09-17 чесно записав у звіт
«дослівної цитати я не знайшов… Не виправляв» — і рядок загубився: він не потрапив ні в
`cross-findings.md`, ні в журнал. Жива довідка казала протилежне.

**Наслідок для роботи.** Рядок «повідомляю, не правлю» у розділі 2 звіту — **не
закриття**. Він закривається лише тоді, коли потрапив у наскрізний файл, який хтось
перечитає. Тому: формулюючи 🔴/🟡 у своєму звіті, дублюй його в розділ 7 «Знахідки для
сусідів» **явним рядком з номером рядка HTML** — так його видно грепом.

**Де реєстр (012):** `dev/build/012-jira/01-authoring/open-claims.md` (складено 2026-09-20
окремим проходом по всіх 22 звітах: 113 записів, 29 закрито раніше, 84 відкрито).

## Найдорожчий клас: категоричне «лише / жодного / завжди» + правильний варіант квіза

Шість із шести 🔴 у 012 виглядали так: твердження про поведінку продукту зі словом
«лише»/«не можна»/«завжди», подане **як факт**, і на ньому стоїть **правильна відповідь**
квіза. Проза після рецензії бувала захищена ⚠, а квіз лишався категоричним — асиметрія,
яку ніхто не бачить, бо квіз читають окремо від прози (`j22` П1, `j17` П4, `j08` П1).

**Прийом:** після проходу по прозі окремо прогнати `explain` і правильні варіанти
питаннями «звідки я це знаю» і «чи не мʼякше за це сказано в прозі поруч».

## Що знаходиться, якщо шукати ще раз

Три з шести 🔴 у 012 закрились живою довідкою **на другому заході** — тому «рецензент не
знайшов» ≠ «джерела немає»:
- «старе посилання після `Move` працює» → людська сторінка
  `jira-software-cloud/docs/migrate-between-team-managed-and-company-managed-projects/`
  («Any existing links to old work item keys will be automatically redirected») — та сама
  сторінка описує процедуру `Bulk change work items`, тобто саме переїзд робіт;
- «картку на Free не питають» → `subscriptions-and-billing/docs/buying-atlassian-cloud-products/`
  («When you set up a site, you start with a Free plan», «We'll ask you to provide payment
  details when you upgrade»);
- «глядач займає місце з десяти» → `subscriptions-and-billing/docs/manage-users-and-user-tiers/`
  + `user-management/docs/default-groups-and-permissions/`.

**Чому перший захід не знаходив:** шукали в продукті, де живе тема (Jira), а джерело
лежало в **сусідньому** продукті доксів (`subscriptions-and-billing`, `user-management`,
`organization-administration`). Індекс слагів варто брати з **усіх** дозволених продуктів,
а не лише з того, про який урок.
