Кожен файл `dev/build/005-ai-terminal/00-research/screens/*.txt` починається рядком із
самою набраною командою (`$ claude --help`), а далі йде вивід. Тому `wc -l` по файлу
рахує вивід **плюс один рядок**.

Приклад: `claude--help.txt` — 243 рядки у файлі, з них 242 рядки виводу
(62 опції `grep -cE '^  (-[a-zA-Z], )?--[a-z]'`, 13 підкоманд). Урок `c02` спершу
казав «повний вивід — 243 рядки»; виправлено на 242 при рецензії 2026-09-06.

**Як застосовувати:** будь-яке число рядків, узяте з `screens/`, звіряти окремо —
автор міг порахувати разом із рядком команди. Числа опцій/підкоманд із того самого
файла надійні, зсув стосується лише загальної кількості рядків.
