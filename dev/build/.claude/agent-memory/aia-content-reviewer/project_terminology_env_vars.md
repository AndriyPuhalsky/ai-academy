У курсі «AI Термінал» одне поняття (environment variable) живе під двома іменами:
**`c03` — «змінна оточення»** (7 входжень, і саме там поняття вводиться з глосою
«(environment variable) … іменоване значення, яке оболонка передає кожній програмі»),
**решта курсу — «змінні середовища»** (`c08`, `c10`, `c13`, `c15`, `c17`, `c18`, `c20`,
`c21`, `c22`).

**Why:** читач знайомиться з терміном у `c03` і потім дев'ять уроків зустрічає інше слово —
для «людини, яка не знає нічого» це виглядає як два різні поняття. Знайдено при рев'ю `c08`
(2026-09-06); не зафіксовано в жодному документі задачі 005.

**How to apply:**
- Правити це **в одному файлі не можна**: вирівнювання за більшістю зачепить `c03`, за
  меншістю — дев'ять уроків. Це рішення власника, у звіт рядком, а не правка.
- Перевірка перед згадкою у звіті (терміни могли вже вирівняти):
  `grep -c "змінн[аиіу]* оточення" modules/claude-code-*.html` проти
  `grep -c "змінн[аиіу]* середовищ"`.
- Той самий тип знахідки шукати й для інших наскрізних слів курсу (`прапорець`, `хост`,
  `домен`): слово, введене в одному уроці, далі має жити під тим самим іменем.
