`python3 dev/build/007-quiz-distractors/check-quiz.py --files <файл>` рахує **тільки довжину**
(найдовша / найкоротша / нічиї) і розкид `answer`. Маркери стилю він не бачить узагалі, тож
файл із «0/6 (0.0 %)» по всіх колонках усе одно може видавати відповідь формою.

**Що перевіряти самому по кожному питанню (швидкий python-прохід по `#quizData`):**
- тире `—`, двокрапка `:`, дужки, капслок стоять **лише** в правильному варіанті;
- **дзеркальний маркер (ловиться тим самим проходом, але окремою умовою):** правильний —
  **єдиний БЕЗ** розділового знака, а всі три дистрактори з двокрапкою/тире. Читає так само:
  «бери гладкий варіант». У j11 (2026-09-18) так було в **4 питаннях із 6** при «0/6» у чекері.
  Лікування: переписати **один дистрактор** на сполучник («…, бо …») замість двокрапки —
  тоді маркер стоїть у двох варіантах із чотирьох і не корелює з відповіддю;
- три дистрактори ділять спільну конструкцію («…, бо …»), а правильний збудований інакше —
  це той самий маркер, лише непомітніший;
- у j07 (2026-09-18) так було у двох питаннях із шести: Q2 — тире лише в правильному,
  Q3 — двокрапка лише в правильному при трьох «бо»-дистракторах.

**Як лікувати, не зачепивши забороненого:** правити **тільки дистрактори** (у курсі Jira квіз
не заморожений, на відміну від 007 — див. [[quiz-frozen-007]]): додати тире/двокрапку одному-двом
хибним варіантам, стежачи, щоб довжина правильного не стала макс./мін. і не було нічиїх.
Після правки — `json.tool` + `check-quiz.py` ще раз.
