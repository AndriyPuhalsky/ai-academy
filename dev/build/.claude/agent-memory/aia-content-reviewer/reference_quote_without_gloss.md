Курс 012 читає **людина не з ІТ**, і англійської їй ніхто не обіцяв. Тому цитата з доксів,
після якої немає українського переказу, для половини читачів — порожнє місце. Це дефект
класу «непояснене слово», а не стилю.

**Why:** у `j14` таких місць було шість, і серед них — **ключ усього блоку 5**: три результати
запуску (`Successful` / `No action` / `Some errors`) стояли лише англійськими означеннями
(«the flow performed an action» …). Читач без англійської не міг зрозуміти найголовнішої
таблиці уроку. Ще чотири: `Scope can only be set at the Global level…`, `…you'll need to
select Update…`, `Site admins will always be able to edit your flows…`,
`…or use a Cron expression…` (саме слово `Cron` ніде не пояснене).

**How to apply:** витягни всі `«…»` з латиницею й подивись **110 символів після** кожної
(python-однорядковик). Якщо ні до, ні після немає українського переказу — додай короткий
переклад **самої цитати**. Це зона рецензента: перекладати ≠ додавати факт, джерело вже
показане автором. Не перекладай числа, які автор свідомо лишив цитатою (у j14 — «past 90
days», «10 consecutive executions»): переказ українською зробить число помітнішим і порушить
§0.1 п. 3.
