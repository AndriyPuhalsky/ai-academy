У курсі 012 два слова живуть у двох значеннях, і автори цього не помічають — обидва випадки
знайдені в `j14` (2026-09-18).

1. **`workflow` (урок 10) проти `flow` (урок 14).** Для англомовного ока різні слова, для
   новачка — одне з хвостиком. `j14` не розводив їх жодним реченням (`grep -i workflow` давав
   лише цитату з доксів). Додано абзац: workflow — шлях роботи по статусах + переходи; flow —
   те, що робить дію замість тебе після події.
2. **«фільтр».** З `j07` це **збережений запит**; `j14` писав «умова — фільтр посеред
   ланцюжка». Виправлено на «перевірка». Той самий конфлікт чекає на `j15` (`Branch`,
   `Lookup`) і `j19` (черги за JQL).

3. **«етап» (хвиля 7, 2026-09-29).** Канон `program.md` п. 20 призначив «етап» українським
   словом для типу `Workstream`, а курс уже перекладав ним **статус**: `j04:280` («`Status` —
   етап, на якому робота зараз»), `j05` ×6, `j06:206` («колонки — етапи»), `j11:181`. Колізію
   створило саме рішення власника, тож англійський напис грепати було марно — видно лише
   `grep` по **українському** слову. У `j04` (дім поняття) додано одне речення-розв'язку;
   наскрізне рішення — за кореневою сесією.

**Why:** новачок будує словник лінійно; друге значення того самого слова тихо ламає модель,
і жоден чекер цього не бачить.

**How to apply:** у рецензії уроків фази 4–5 грепай `workflow`, `фільтр`, `правило`, `крок`
і питай «у якому значенні читач бачив це слово раніше». Правити — зона рецензента: обидва
поняття вже введені, нового факту не з'являється. Перевір, чи `j15`/`j19` не повторюють ту
саму пару. **Коли канон задає нове українське слово для англійського терміна — грепай це
українське слово по всьому курсу ДО того, як приймати правку.**
