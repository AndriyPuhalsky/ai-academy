Кожне «з нею ти вже знайомий за модулем N» / «нагадування з модуля N» в `modules/claude-code-*.html`
перевіряти **grep-ом по файлу модуля N**, а не на віру.

**Why:** у `c07` каптіон під першим екраном стверджував, що `grep` пояснено в модулі 1 —
у `claude-code-01.html` слово `grep` не трапляється жодного разу (є в `c03` і `c06`).
Автор пише в потоці й пам'ятає курс приблизно; для читача-новачка хибне посилання
означає «повернувся й не знайшов». Це перевірюваний факт про курс, тому фікс — у зоні редактора.

**How to apply:** перед правками зібрати всі згадки «модул\w+ \d» у своєму файлі й для кожної
зробити `grep -o '<термін>' modules/claude-code-NN.html | wc -l`. Нуль — прибрати посилання,
лишивши пояснення на місці (не переносити тему й не дописувати факт).
Тим же способом перевіряти, чи поняття взагалі введене раніше **в курсі**
(контракт вимагає введення при першій появі в курсі, не в модулі): у `c07` так знайдено
`фіче-прапорці` — 0 згадок у `c01`–`c06`, тобто перша поява без пояснення.
**Друга форма тієї ж пастки (знайдено в `c15`, 2026-09-06):** посилання не на введений термін,
а на **тему цілого модуля**. `c15` двічі обіцяв «про сам git — модуль 21», але `claude-code-21.html`
сам пише: «git у курсі не вивчається окремо» — там лише один абзац-визначення й робочі команди.
Тобто перевіряти треба не лише «чи слово там є», а й «чи модуль справді про це».
Джерело для звірки — рядок модуля в `00-research/program.md` (там `c21` = «Наскрізний проєкт
і робочі звички», git усередині як інструмент, а не як тема).

**Третя форма (курс Jira, `j13`, 2026-09-18):** посилання на урок, у якому теми **ще/взагалі немає**.
`j13` у блоці «чого тут немає» відсилав за «пошуком за спринтом» до уроку 7 — `grep -ci "спринт"
modules/jira-07.html` дає **0**. Тема не існує ніде в курсі (поле JQL `Sprint` лишилось лише
знахідкою для довідника). Фікс — замінити на те, чим урок 7 справді є («пошук запитом JQL»),
а тему не дописувати. Прийом той самий: `grep` по файлу адресата **до** того, як повірити рядку.

**Четверта форма (курс Jira, `j22`, 2026-09-19): правильна тема — сусідній урок.** `j22` відсилав
за апселами `Ask AI` / `Improve Task` до «уроку 2», але в `jira-02.html` слів `Rovo` і `Ask AI`
**0 входжень**: їхній дім — `jira-03.html` (ЧаПи «Що це за кнопки Ask AI, Improve і See plans?»),
а урок 2 — про `See plans`. Тут `grep` дав не «нуль по курсу», а **нуль у названому файлі й
влучання в сусідньому**, тому фікс однозначний: замінити номер, нічого не дописуючи.
Дешевий спосіб знайти правильний номер — `grep -c "<напис>" modules/jira-*.html | grep -v ":0"`;
курс часто вже містить готову відповідь у чужому уроці (`j13`: «як і кнопка See plans з уроку 2
та Ask AI з уроку 3»).
