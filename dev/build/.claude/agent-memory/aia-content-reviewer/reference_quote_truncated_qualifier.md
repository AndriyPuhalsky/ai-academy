Скрипт звірки цитат каже «OK», коли фрагмент знайдено в тексті сторінки. Це **не доводить**, що
цитата повна. У j20 (2026-09-19) двічі стояло «Members of this group won't count towards your
bill», а в доксах речення продовжується: «**(unless the user holds another billable role)**» —
і саме дужка описує випадок, який урок поруч і розбирає (клієнт порталу, якого додали ще й
користувачем Jira).

**Як перевіряти:** після того, як цитату знайдено, друкувати не лише збіг, а **200–300 знаків
після** нього; дивитись, чи речення закінчується там, де закінчується цитата. Те саме — для
переліків: «у переліку стоять X і Y» перевіряти на наявність речення-винятку нижче (там само,
`export-issues`: «Although automation flows aren't automatically exported, you can manually export
and import automation flows»).

**Що робити:** обрізання перед уточненням — дефект класу «непідтверджений факт», а не косметика.
Дужку можна дописати самому (джерело показане у звіті); якщо в колонці таблиці немає місця —
ставити «…» як знак обрізання, а повну цитату давати в прозі.
