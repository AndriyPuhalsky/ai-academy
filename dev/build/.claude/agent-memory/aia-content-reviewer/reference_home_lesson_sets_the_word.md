Коли урок переказує англійську назву українською («верхній рівень ієрархії», «поверх»,
«етап»), **не суди за своїм файлом** — порахуй обидві форми по всіх `modules/jira-*.html`
і подивись, яка стоїть в **уроці-домі** поняття (`program.md` розділ 4).

**Як рахувати** (обережно з морфологією — `рівень` не матчиться патерном `рівн\w*`, а перенос
рядка в HTML розриває словосполучення):

```bash
python3 - <<'EOF'
import re,glob
for f in sorted(glob.glob('modules/jira-*.html'))+['jira-ref-automation.html']:
    s=re.sub(r'\s+',' ',open(f,encoding='utf-8').read())
    a=len(re.findall(r'верхн\w*\s+(?:рівень|рівня|рівні|рівнем)',s)); b=len(re.findall(r'поверх',s))
    if a or b: print(f,'рівень',a,'| поверх',b)
EOF
```

**Чому:** хвиля 7 задачі 012 (2026-09-29). Група ④ (j14, j15, `jira-ref-automation`) писала
«верхній рівень ієрархії» — 13 разів, «поверх» 0. Дім поняття **j04** вживає «поверх» 23 рази
(j11 — 21, j06 — 3, j05 — 3), «верхній рівень» — рівно 1. Читач, який вивчив «три поверхи
ієрархії», у 14-му уроці зустрічав інше слово без містка. Формулювання — зона рецензента, тож
зводив я, а не повідомляв.

**Друга половина правила:** перефраз часто стирає розрізнення, яке дім вводить спеціально.
j04 прямо застерігає «**поверх і назва типу — різні речі**», а група ④ писала «`Campaign` —
так зветься верхній рівень ієрархії», тобто ототожнювала назву типу з поверхом. Правильно —
«**тип** верхнього поверху ієрархії». Шукай у домі фразу «X і Y — різні речі» й перевіряй,
чи твій файл їх не злив.

**Як застосовувати:** у проході «по словах» — після пошуку заборонених зворотів. Правити
своє; якщо сусід у тій самій хвилі звів у зворотний бік — рядок у §7 для кореневої сесії
(розбіжність знімається одним наскрізним проходом, а не двома агентами назустріч).
