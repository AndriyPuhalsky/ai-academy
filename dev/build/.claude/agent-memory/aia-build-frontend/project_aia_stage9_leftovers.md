**Факт: `css/custom.css` видалений 2026-09-07 (коміт `55d33a4`). Стара мова більше не
існує; каскад — `tokens.css` → `components.css` → сторінковий (`claude-code.css` /
`roadmap.css`) → Tailwind CDN → `tw-theme.js`.**

**Why:** останній крок задачі 010. До видалення стара мова маскувала дірки в новій —
саме тому етап 9 і робиться останнім: він і є перевірка міграції.

**How to apply — чого система 009 НЕ несе (виявлено A/B-заміром, не читанням):**

| Що | Наслідок | Де |
| -- | -------- | -- |
| `.term__dots` box-shadow 12/24 px | три кружечки термінала → **один** | 107 терміналів |
| `.ds-ftr a` (0,1,1) б'є `.rm-entry` (0,1,0) | точка входу в роадмап лишається `inline-flex`, `.rm-entry__rule { grid-column: 1/-1 }` дає ширину 0 → підкреслення зникає | index, architect, claude-code, roadmap |
| `.term__title { flex; min-width: 0 }` | `text-overflow: ellipsis` не спрацьовує | 107 |
| `.term > .term__body { tab-size: 2 }` | табуляція в CLI-виводі стає 4 | 107 |
| `.term__line--pick { min-width: 100% }` | підсвічений рядок не на всю ширину | hero Термінала |
| `::selection` і `scrollbar-color` | системні світлі на темному сайті | усі 66 |

**Метод, який це знайшов (повторити наступного разу):** відкрити сторінку в `<iframe>`,
зняти `getComputedStyle` **усіх 476 властивостей + rect** кожного елемента, вимкнути
конкретний stylesheet через `sheet.disabled = true` у CSSOM, зняти ще раз, здифити.
⚠ Скорочений список властивостей бреше: перший прогін із 27 властивостями **не показав**
ні `box-shadow`, ні `margin-right`, тобто пропустив головну регресію.
⚠ `scrollbar-color` успадковується від `html` і дає шум на 100 % елементів — виключати.

**Друга пастка методу:** заміна хексів на `" + P.x + "` у JS **залежить від лапок
літерала**. У `'<div style="color:#8a7f6f">'` (одинарні зовні) підстановка з подвійними
лапками дає **текст усередині рядка**, а не конкатенацію — `node --check` мовчить, бо це
валідний JS. Правильно: визначати діючий лапковий контекст для кожної позиції, проходячи
префікс рядка зліва направо.
