Замір геометрії через `mcp__claude-in-chrome` у AIA має три пастки, кожна з яких
мовчки дає хибне число.

**1. `resize_window` не керує лейаут-вʼюпортом надійно.** У сесії 011 (хвиля 2)
після `resize_window(1280, 900)` сторінка звітувала `innerWidth 1440`,
`outerWidth 784`, `devicePixelRatio 2`; після `resize_window(900, 800)` геометрія
взагалі не змінилась, а пізніше та сама вкладка віддала `innerWidth 1280`.
**Завжди читати `innerWidth`/`innerHeight` тим самим викликом, що й геометрію**, і
записувати у звіт фактичну ширину, а не замовлену. Для точних ширин (390, 768,
1024) — власний Chrome по CDP (`dev/build/011-open-tails/stand/`), не розширення.

**2. Урок гостя віддає нульові (і навіть відʼємні) ширини.** `js/module.js`
ставить `hidden` на всі діти `main` під замком, тож `offsetHeight − clientHeight`
дає `-2` (самі бордери). Обхід для заміру: `document.getElementById('aiaGate')
.remove()` + зняти `hidden` з дітей `main` + `dispatchEvent(new Event('resize'))`.
Фальшивий ключ `localStorage['sb-probe-auth-token']` знімає лише **ранній**
замок (`guestForSure`), пізній усе одно прийде після відповіді Supabase.
**Ключ обовʼязково прибирати** — інакше наступний гостьовий замір хибний.

**3. Читання атрибута одразу після програмної прокрутки бреше.** Кілька
`el.scrollLeft = …` + `await setTimeout` в одному інжектованому скрипті дали
`data-scroll-fade`, що відставав на крок. Правильно: одна дія — один виклик
`javascript_tool`, або перевіряти стан у наступному виклику.

**Що працює добре:** `getComputedStyle` для доказу, що правило застосувалось;
обхід `document.styleSheets` (`cssRules`) — доказ, що CSS розібрався без помилок
(рахувати правила, а не дивитись очима); `performance.getEntriesByType('paint')`.

Див. також [[wave-report-via-final-message]].

## Додано 2026-10-01 (012, власний Chrome по CDP)

- **Програмний `.focus()` НЕ вмикає `:focus-visible`.** Кільце фокуса «зникає» без причини, і
  замір виглядає як дефект доступності. Тиснути справжній `Tab` через `Input.dispatchKeyEvent`.
- **`Enter` / `Space` через CDP вимагають ТРЬОХ подій** — `rawKeyDown` + `char` + `keyUp`.
  Лише з двома браузер не синтезує `click`, і кнопка «не працює»: у 012 через це
  `aria-expanded` випадайки читався `false` після «натискання» Enter.
- **`Emulation.setScriptExecutionDisabled` не глушить `Runtime.evaluate`.** Скрипти сторінки
  не виконуються, а власний замір працює — тобто стан «без JS» можна міряти, а не лише
  читати `DOM.getOuterHTML`.
- **`Page.addScriptToEvaluateOnNewDocument` — єдиний спосіб виставити `data-motion="calm"`
  ДО завантаження.** Поставлений після завантаження пресет дефекту D-01 не відтворює.
  ⚠ У цьому скрипті `document.documentElement` ще `null` — потрібен `setTimeout`-цикл.
- **`#aiaGate` знімається трьома рядками:** прибрати сам вузол, зняти `hidden` з усіх дітей
  `#main`, зняти `data-aia-gate` з `<html>`. До цього всі ширини на уроці нульові, і
  `js/jira-win.js` свідомо не чіпає вузол із `clientWidth === 0`.

## Додано 2026-10-01, друга сесія (012, коло фіксів D-01)

- **Хибнопозитив «текст у два рядки» на 0,5 px.** Лічильник рядків виду
  `rects.forEach(r => ys[Math.round(r.top)] = 1)` рахує інлайновий `<code>` за
  окремий рядок: у нього інший кегль, і на ТОМУ САМОМУ рядку його rect стоїть на
  0,5 px вище. Комірка `У <code>-p</code>` виходила «2 рядки по 1,5 знака» —
  тобто «зламана колонка» там, де все в один рядок (висота комірки 41,2 px, як у
  сусідньої однорядкової). **Групувати рядки з допуском ≥ 6 px.** Через цю
  похибку числа QA кола 1 на D-01 були завищені на 2–4 таблиці на ширину.
- **«До» міряти тим самим кодом метрики, що й «після».** Не порівнювати свої
  числа з числами зі звіту сусіда: `git archive HEAD | tar -x -C <tmp>` + другий
  `http.server` на іншому порту — і той самий скрипт ходить на обидва.
- **`Page.captureScreenshot` на дуже високій сторінці (46 000 px).** `clip` +
  `captureBeyondViewport: true` переразкладає документ, координати їдуть;
  `clip` у віконних координатах далеко прокрученої сторінки дає **порожній PNG**.
  Робоче: підігнати ВИСОТУ вікна під блок, прокрутити блок під липку шапку
  (запас ~70 px) і знімати все вікно **без clip**. Перед `scrollTo` явно ставити
  `document.documentElement.style.scrollBehavior = "auto"`.
- **Інжектований `<style>`, доданий у `head` у рантаймі, бʼє Tailwind CDN не
  завжди.** Для A/B із утилітами (`min-w-[Nrem]`) надійніше селектор із більшою
  вагою (`#sec table.ds-tbl` або подвоєний клас), інакше «варіант» мовчки не
  застосувався, і числа виглядають як «нічого не змінилось».
