Закрито в 012 (коло фіксів 1, дефект D-01 QA). Механіка універсальна для будь-якої
таблиці `width: 100%` з авторозкладкою, не лише для AIA.

## Дефект «таблиця стискається замість того, щоб прокрутитись» має ДВІ половини

1. **`overflow-wrap: anywhere`** (у AIA — `.ds-tbl th, .ds-tbl td` і окремо
   `.ds-prose code`) робить min-content комірки рівним **одному символу**. Тому
   авторозкладка завжди знаходить спосіб втиснути таблицю в контейнер,
   переповнення не виникає ніколи — і `overflow-x: auto` обгортки, маска-підказка,
   постійна смуга й `tabindex` стоять мертві.
2. **У таблиці немає `min-width`.** Коли слово перестає різатись, min-content стає
   чесним, але `width: 100%` далі тримає таблицю в контейнері.

**Жодна половина не закриває дефект сама** (замір на 167 таблицях × 5 ширин):
лише `break-word` → розривів усередині токена 0, але 6–8 колонок-смужок;
лише `min-width` → смужок 0, але 160 розрізаних токенів на 1280.

## ⚠ `min-width` на КОМІРЦІ (`th/td`) ламає розподіл ширини

Виглядає найелегантніше («колонка не вужча за 10 знаків») і **працює навпаки**:
у таблиці з авторозкладкою задана `min-width` на комірці перетворює колонку на
«колонку із заданою шириною», і Chrome ділить надлишок не за вмістом, а майже
порівну. Живий замір: 3 колонки стали 94 / 117 / 105 px, і колонка довгої цитати
**схудла з 232 до 105 px, виросла з 14 до 35 рядків**.
**`min-width` ставити на `<table>`.** На обгортку-скролер — ніколи: вона мусить
лишатись по контейнеру, інакше прокручувати нічого.

## `white-space: nowrap` на колонці — безпечний важіль

Не реєструється як «задана ширина», тож пропорційний розподіл зберігається. Лікує
колонку-тег («Урок» зі значенням «14, 15», заголовок «У -p»), яка переноситься
через кому, і при цьому **зменшує** висоту блока. Тільки для тегів, не для речень.

## Другий критерій, якого метрика «вузької колонки» не бачить

«Колонка < 60 px і ≤ 2,6 знака в рядок» не ловить розрізане посеред себе імʼя в
нормальній колонці (`project = MARK` → `proje/ct =/MARK`). Міряти окремо: кожне
слово в `<span>`, розрив зараховувати **лише між двома буквоцифрами** (інакше в
дефект потраплять законні переноси після дефіса й слеша — `company-managed`,
`support.atlassian.com/…`).
