## Що показує компактна форма (за замовчуванням, «Simple create as default: on» у System settings)
- Шапка модалки: чіп спейсу **KAN** · чіп типу **Task** (обидва — випадайки) · іконки «відкрити збоку», **розгорнути у повну форму** (⤢), закрити ✕
- Поле **Summary** (заголовок, обовʼязкове)
- Поле опису з плейсхолдером «Add a description or type / for actions and Rovo»
- Ряд чіпів-полів: **Automatic** (assignee) · **Parent** · **Medium** (priority) · **Labels** · **Due date**
- Внизу: іконка вкладення · чекбокс **Create another** · синя кнопка **Create**
- Спливашка-підказка: «**A simpler way to create** — If you need more fields, click the expand icon to view the full form.» **Got it**
