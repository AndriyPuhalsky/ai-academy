# Квізи 012 «Jira з нуля» — лексичні маркери «бо / тому / лише / завжди» (завдання для `aia-quiz-editor`, 2026-09-30)

Сьогодні 2026-09-30. Уроки курсу написані й відрецензовані; довжину варіантів уже вирівняно («правильна = найдовша» —
7 з 158 у 22 уроках, в іспиті 0 з 26), пунктуаційних маркерів 0. Лишилась **підказка словом**, якої старі перевірки не
бачили: в окремому питанні слово стоїть **лише в правильному варіанті** (учень бачить «тому…» один раз — і обирає його)
або **в усіх дистракторах, крім правильного** (три «…, бо …» проти одного гладкого). З 2026-09-30 це міряє
`check-quiz-markers.py --lexical`. Твоя робота — прибрати такі маркери у своїй партії, **правлячи лише дистрактори**.

## Що саме вважається маркером (для кожного питання, слово — ціле, без регістру)
- ✗ слово є **лише** в правильному варіанті → додай його природно **хоча б в один** дистрактор (так, щоб дистрактор
  лишився хибним і звучав як речення цього уроку; «тому» / «бо» — через хибну причину, «лише» / «завжди» — через хибне
  обмеження);
- ✗ слово є **в усіх** дистракторах, а в правильному немає → перепиши **хоча б один** дистрактор без цього слова.

## Межі (тверде, як у твоєму визначенні)
- Недоторканні: текст `options[answer]`, `q`, `explain`, `answer`, кількість і порядок питань і варіантів.
- **Дистрактор лишається хибним за чинним текстом уроку.** Обережно з прибиранням «лише» / «завжди»: «X працює лише на
  Premium» — хибне, а «X працює на Premium» може стати **правдою**. Після кожної правки спитай себе: «якби учень обрав
  це, `explain` і текст уроку пояснили б, чому він помилився?» Дистрактор не може стояти на тому, що урок подає під ⚠
  («не перевіряли», «за документацією») — такий «хибний» варіант курсом не спростований.
- **Не зламати довжину:** після правки правильна не має стати найдовшою чи найкоротшою там, де раніше не була. Тримай
  дистрактор у межах ±20 % від правильної.
- **Не вносити нових маркерів:** пунктуація `— : ; → «` і ті самі чотири слова — правка не має створити маркер в інший бік.
- Правиш лише блок `#quizData` своїх файлів. Текст уроку, верстка, інші файли — ні. Git не виконуєш.
- Курс описує безкоштовний план Jira; факти дистрактора — лише з тексту цього уроку (не з памʼяті моделі).

## Перевірка (після кожного файла; вивід — у звіт)
```bash
cd /Users/ander1.sage/Downloads/AIA
python3 - <<'PY'
import re, json
s = open("modules/<файл>.html", encoding="utf-8").read()
m = re.search(r'<script type="application/json" id="quizData">(.*?)</script>', s, re.S)
json.loads(m.group(1)); print("json ok")
PY
python3 dev/build/007-quiz-distractors/check-quiz.py --files modules/<файл>.html
python3 dev/build/007-quiz-distractors/check-quiz.py --files modules/<файл>.html --verify <BASELINE>
python3 dev/build/012-jira/01-authoring/check-quiz-markers.py --lexical --files modules/<файл>.html   # «Маркерів: 0»
```
`<BASELINE>` — у завданні. `--verify` має бути чистим: він доводить, що правильні тексти, `q`, `explain` і кількість
питань не змінились. **Shell:** кожну команду починай з абсолютного `cd`.
