Правила руху, встановлені задачею 003 і придатні для всіх наступних сторінок AIA.

**Масштаб scroll-driven.** Ціль — **не більше 2–3 ScrollTrigger на цілу сторінку**. Число
не з голови: на `anthropic.com` (першоджерело нашої палітри, теж на GSAP) виміряно рівно
два тригери на весь лендінг. Поява карток/рядків робиться `IntersectionObserver` + CSS
(той самий механізм, що вже є в `js/ui.js` для `.reveal`), інакше кількість тригерів росте
лінійно з даними.

**Виміряні числа, які можна брати без нового ресьорчу:**
- `scrub: 0.8` і `{ start: "center 70%", end: "center 40%" }` — фінальний блок anthropic.com;
- `cubic-bezier(.16,1,.3,1)` — переходи секцій Cloudflare Year in Review;
- `cubic-bezier(.17,.84,.44,1)` — повільна поява kononenkogroup.com;
- `pulse 1.4s ease-in-out infinite` — живий маркер Cloudflare (нижня межа діапазону 1.4–2.5с).

**Один безкінечний цикл на сторінку.** Якщо loop-анімацій більше однієї, «зараз» перестає
бути центром. Кілька елементів можна анімувати одним твіном — це лишається одним loop.

**reduced-motion працює ПОІМЕННО.** Блок у `css/custom.css:844–866` не автоматичний: кожен
новий токен тривалості/затримки/зсуву/масштабу треба дописати туди руками. Найдешевший
спосіб не забути — читати всі числа руху в JS із CSS-змінних (`getComputedStyle`), тоді
обнулення токенів вимикає і GSAP.

**Ліцензія GSAP (перевірено на gsap.com/licensing, чинне з 30.04.2025):** усе GSAP,
включно з колишніми «клубними» плагінами (SplitText, MorphSVG, DrawSVG, MotionPath),
безкоштовне для комерційного використання. Але перевіряти щоразу самому — це вимога
`dev/design/CLAUDE.md`, і формулювання на сайті може змінитись.

**Пастки, вже спіймані скріншотами:**
- `transform-box: fill-box` у CSS + матриця GSAP на тому самому SVG-елементі = елемент
  їде. Або CSS, або GSAP — не обидва.
- `stroke-dashoffset` несумісний із пунктиром. Якщо лінію треба «дописувати» і вона
  пунктирна — тільки `clipPath` із прямокутником, що масштабується.
- `tween.progress()` усередині власного `onUpdate` кидає помилку на першому виклику;
  використовуй проксі-обʼєкт `{p:0}` з `ease:"none"`.

**How to apply:** застосовуй на будь-якій анімованій сторінці AIA, а не лише на роадмапі.
