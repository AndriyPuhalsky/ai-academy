Ухвалено власником у задачі 001 (`00-decisions.md`, §7 найсвіжіший). Це вхідні дані для
наступних задач, а не пропозиції.

- **Кнопка провайдера — офіційна, як є.** Світлий прямокутний OUTLINE, висота **40 px**,
  не масштабувати до 44. Логотип не перефарбовувати, свою рамку не малювати.
- **44×44 — це AAA (SC 2.5.5), не мінімум.** Мінімум AA — **24×24** (SC 2.5.8).
  Не писати «провал тач-таргета» для 40 px контролів.
- **Google Sans не вбудовувати й не фетчити** — навіть попри те, що
  `fonts.googleapis.com/css2?family=Google+Sans` віддає 200. Підпис — IBM Plex Sans
  Medium. Критерій «нуль мережевих запитів по цьому шрифту» перевіряється щоразу.
- **Рух службових діалогів:** 150–220 мс, підложка й картка **разом, без каскаду**,
  вихід коротший за вхід.
- **Режим `у межах системи`** для 001; нові токени — лише за потреби (введено
  `line-strong` = `#736A5E`, `clay-deep` змінено на `#C4674A`). Будь-яка зміна значення
  палітри = **38 однакових правок** у `tailwind.config` кожного HTML.
- **Головний референс — R01 (Cal.com):** провайдер → хайрлайн «або» → поля →
  повноширинна головна кнопка внизу.

**Why:** власник тримає старт кожного кроку за собою і не любить, коли вже ухвалене
відкривають наново як «варіант».
**How to apply:** вісь варіантів брати з того, що прямо віддано агентам
(`00-decisions.md` §3 п.3), а не з того, що вже вирішено.
