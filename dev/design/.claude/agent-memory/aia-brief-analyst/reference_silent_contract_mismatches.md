Найдорожчий клас дефектів у цьому проєкті — **не зламана верстка, а мовчазна
розбіжність контракту**: CSS чекає одного, JS дає інше, помилки немає, сторінка
малюється, і дефект помічають місяцями пізніше. Знайдено чотири штуки за одну
годину читання коду під час специфікації 010 (2026-09-07) — тобто це не рідкість.

**Виміряні приклади:**
1. `_base/components.css:527` селектує `.ds-snav__item[aria-current="true"]`, а
   `js/module.js:165` ставить `aria-current="page"`. Поточний урок у сайдбарі просто
   не отримує акценту. Правильне значення для пункту навігації за WAI-ARIA — саме
   `page`, тож правити треба CSS, а не JS.
2. `_base/components.css:557` малює літеру варіанта через `content: attr(data-key)`,
   а `js/quiz.js:107` ставить лише `className = "quiz-opt"`. 57 сторінок без «А/Б/В/Г».
3. `js/quiz.js:126,131` дописує `✓ ` / `✗ ` **у сам текст** варіанта, а система
   малює ті самі гліфи псевдоелементом → подвоєння.
4. **Найгірший тип: тихий fallback.** `js/roadmap-motion.js` читає 36 імен токенів
   через `num(name, fallback)`. Перейменуєш токен у CSS — JS мовчки візьме зашите
   число, і роадмап продовжить анімуватись «майже правильно». Те саме в
   `js/claude-code-motion.js` (15 імен). Плюс `getComputedStyle` не обчислює `calc()`
   для незареєстрованих custom properties → `parseFloat` = `NaN` → той самий fallback,
   і рух лишається живим при `prefers-reduced-motion`.

**Why:** у цьому проєкті розмітка й стилі народжуються в різних місцях — половина
класів приходить із рядків усередині `js/*.js`, а не з HTML. Тому «подивитись на
сторінку» дефект не ловить: сторінка виглядає нормально, просто гірше, ніж мала б.

**How to apply:** пишучи будь-яку спеку, що зводить новий CSS зі старим JS, окремо
перевіряти три речі й називати їх у розділі пасток:
(а) кожен селектор з атрибутом — чи ставить JS **саме це значення**;
(б) кожен `content: attr(...)` — чи є той атрибут у розмітці, яку будує JS;
(в) кожне `getComputedStyle`-читання токена — чи є в нього fallback, і що станеться
при перейменуванні. Перевірка — `grep` по JS, не погляд на екран.
