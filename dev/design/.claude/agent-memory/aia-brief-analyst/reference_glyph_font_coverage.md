Перевірено фактично 2026-10-01 (специфікація 012): завантажено CSS
`fonts.googleapis.com/css2?family=Prata&family=Golos+Text:wght@400;500;600&family=JetBrains+Mono:wght@400;500`
і розібрано `unicode-range` усіх **14** `@font-face` (latin, latin-ext, cyrillic,
cyrillic-ext, greek, vietnamese по трьох гарнітурах).

**Не покриті жодною підмножиною:**
`①`–`⑧` U+2460–2467 · `☑` U+2611 · `⚡` U+26A1 · `→` U+2192 · `▲` U+25B2.
**Покриті (у підмножині `latin`):** `ʼ` U+02BC (український апостроф — підтверджує
знахідку 009), `›` U+203A, `·` U+00B7.

**Наслідок:** ці гліфи малює **системний фолбек** — macOS Apple Symbols / Hiragino,
Windows Segoe UI Symbol, Android Noto — з чужими метриками й базовою лінією, і наш CSS
на них не впливає. Браузер навіть не запитує файл шрифту: якщо кодпойнта немає ні в
одному `unicode-range`, фолбек неминучий незалежно від того, що лежить у повній
гарнітурі.

**Why:** це не новина — `ds-diag__fallback::before{content:"▲"}` і `ds-note--warn` так
живуть у проді з 010. Але 012 множить випадок: **190 міток `win__mark` у 62 вікнах**
і 33 гліфи типу роботи. Там, де один ▲ непомітний, 190 міток у фіксованій колонці поруч
із текстом видають різницю метрик одразу.

**How to apply.** Гліф у розмітці — не привід його «виправити»:
(1) **літерал лишається** (копіюється разом із текстом, а контент курсів заморожений);
(2) гліф **пришпилюється до коробки фіксованої ширини** — прийом `term__mark` (1ch/2ch
у `css/components.css` §12), щоб заміна гліфа не зсувала сітку;
(3) елементу дається **власний `font-family` з явним фолбек-стеком**, а не успадкований;
(4) критерій приймання формулюється як **A/B із заміною гліфа на пробіл**: та сама
кількість рядків і та сама ширина — бо на машині агента фолбек інший, ніж у власника;
(5) для нумерації списку тими самими гліфами — `@counter-style { system: fixed; symbols:
"①" … ; fallback: decimal }`, інакше мітка ① у схемі і пункт «1.» у легенді різні на вигляд.

**Чого не робити:** не замінювати літерали на CSS-counter «щоб було чисто» — ламається
копіювання й `Cmd+F`; не додавати четверту гарнітуру заради восьми гліфів (155.9 КБ
шрифтів — виміряна причина вибору варіанта A в 009).
