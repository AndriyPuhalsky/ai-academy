Чотири речі в `css/custom.css`, на яких легко зламати макет мовчки. Перевірені 2026-09-03.

1. **`@media (prefers-reduced-motion: reduce)` працює за ПОІМЕННИМ списком токенів**
   (`css/custom.css:1034+`). Новий токен тривалості туди сам не потрапляє й лишається
   живим. Це вже було критерієм приймання 003 і стало Б-13 у 005. Виняток, який роблю
   свідомо: токен-швидкість, на який ділять (`--speed-term-cps`) — нуль дав би `Infinity`,
   тож його вимикає гілка в JS.

2. **`.prose-aia pre` має специфічність (0,1,1) і б'є будь-який одинарний клас (0,1,0)**
   всередині сторінок уроків: накидає другу рамку, другий фон і підміняє `white-space: pre`
   на `pre-wrap`, від чого моноширинні колонки розсипаються. Розв'язання — оголошувати
   полотно як `.term > .term__body` (0,2,0) з ЯВНИМ скиданням семи властивостей:
   margin, border, background, border-radius, padding, white-space, word-break.

3. **`<button>` без явного `background` бере світлий ButtonFace браузера** — на темній
   темі текст ivory зникає на світлому. У `<a>` тієї ж проблеми немає, тому баг ловиться
   не одразу: та сама кнопка виглядає правильно, поки вона посилання.

4. **`.prose-aia li::marker { color: #D97757 }` (css/custom.css:191), схоже, мертве:**
   Tailwind preflight ставить `list-style: none`, а `.prose-aia ul` повертає лише
   `padding-left`. Маркерів у списках уроків немає. Не моя зона — фіксую для сесії
   реалізації.

5. **Медіа-запит НЕ додає специфічності.** `@media (max-width: 640px) { .x { min-width: 8ch } }`,
   що стоїть у файлі **вище** за звичайне `.x { min-width: 0 }`, програє йому — і правило
   мовчки не діє. Спіймано в 009 на `.ds-hdr__brand`: бренд у мобільній шапці стискався до
   нуля. Правило: блок мобільних перевизначень компонента ставити **після** всіх його
   базових оголошень, а не поруч із базовим правилом блока.

6. **`minmax(<фікс>, 1fr)` у `repeat(auto-fill, …)` не стискається нижче фікса.**
   `minmax(var(--w-narrow), 1fr)` при 672px дає +376px горизонтального скролу на 320.
   Завжди `minmax(min(<фікс>, 100%), 1fr)`. Те саме для будь-якої фіксованої `width`
   усередині контейнера з паддінгом (у 009 так розпирав `.ds-paper__rule` 280px —
   репліка хайрлайна з PDF сертифіката).

Плюс правило проєкту, яке з цього випливає: **одна задача — один префікс класів**
(`aia-` у 001, `rm-` у 003, `term-` + `cc-` у 005), і компонент та сторінка — два окремі
CSS-файли, префікси не змішуються.
