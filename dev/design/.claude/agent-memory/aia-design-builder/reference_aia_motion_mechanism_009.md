Задача 009 замінила **57 поіменних перевизначень** `prefers-reduced-motion` (три покоління,
з коментарями «нове туди САМО не потрапляє» тричі) на механізм із двох рядків.

```css
@media (prefers-reduced-motion: reduce) { :root { --motion: 0; --loop-state: paused; } }
```

Усе інше будується з двох похідних одиниць:
`--dur-u: calc(var(--motion) * var(--motion-scale) * 1ms + 0.0004ms)` і
`--move-u: calc(var(--motion) * var(--motion-travel) * 1px)`.
Правила: тривалість = `calc(<L1-число> * var(--dur-u))`; зсув = `* var(--move-u)`;
масштаб = `calc(1 ± var(--motion) * <дельта>)`; кожна `infinite` має
`animation-play-state: var(--loop-state)`; токен-швидкість із суфіксом `-cps` (на нього
ділять) НЕ множиться на `--motion` — його гілку бере JS.

**Дві пастки, обидві виміряні, обидві коштували б кола QA:**

1. **`getComputedStyle` не обчислює `calc()` для незареєстрованого custom property** —
   повертає сирий рядок, `parseFloat` дає `NaN`, помічник `ms()` тихо бере fallback,
   і рух лишається живим при `reduce`. На скріншоті цього не видно.
   Закривається ДВОМА правилами одночасно: JS читає лише `--motion*` і сирі `--p-*`
   і множить сам; кожен складений токен зареєстрований через `@property`.

2. **Епсилон множиться на сире число токена.** Спека пропонувала `+0.001ms`, але
   найдовший токен (1900) давав 1.9 мс і провалював критерій «≤1 мс». Правильне
   значення — **`0.0004ms`**: 1900 × 0.0004 = 0.76 мс під порогом, а найкоротший (90)
   лишається ненульовим (0.036 мс), тобто `transitionend` приходить і JS не зависає.
   Нуль ставити НЕ можна: нульова тривалість не породжує подій узагалі.

**Драбина тривалостей має призначення в назві, а не номер** (форма `@carbon/motion@11`):
tap 90 · exit 130 · hover 150 · enter 180 · state 220 · reveal 380 · sheet 400 ·
page-in 520 · count 900 · shimmer 1400 · loop-pulse 1900. Кривих рівно пʼять.

**Стагер — не фірмовий прийом преміального сайту:** з пʼяти просканованих він є в нуля.
Cap 8 обовʼязковий (30 карток без cap = 2249 мс до останнього, з cap = 982 мс).
На уроці стагер = 0.
