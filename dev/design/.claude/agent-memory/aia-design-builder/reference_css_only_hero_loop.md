Побудовано в 012 (hero «Jira з нуля»: курсор тягне картку між статусами,
лічильники перекидаються, слід росте, автоматизація бʼє). Сім синхронних
доріжок, цикл 5.2–8.1 с, три темпи, пауза, зупинка поза екраном — **нуль GSAP**.

**Чотири причини, чому CSS виграв у GSAP саме тут:**
1. **Синхронність тримається конструкцією.** Усі доріжки мають одну
   `animation-duration` (один складений токен) і нульову затримку — розійтись
   не можуть у принципі. Таймлайн на `rAF` може.
2. **Гасіння безкоштовне.** Тривалість = `calc(<L1> * var(--dur-u))`, тож при
   `--motion: 0` цикл не йде. GSAP довелось би окремо вчити читати
   `--loop-state` — це дефект D-11 задачі 010.
3. **Нерендерена вкладка не дає `rAF`** — таймлайн GSAP завмирає на випадковому
   кадрі (виміряно в 010: `opacity: 0.3458`). CSS-анімація привʼязана до часу
   документа й після повернення вкладки показує правильний кадр.
4. Мінус три файли з CDN на лендінгу.

**Сім правил механізму:**
- **Стан спокою = ФІНАЛЬНИЙ кадр.** Клас, що вмикає анімації, **відсутній у
  поданому HTML** — його ставить JS після вимірювання. Лабораторія 012 на
  31 видимому знаку: «ховає CSS» і «атрибут у HTML, JS його знімає» дають
  **0 без JS**, «спокій = фінальний кадр» дає **31**.
- **JS міряє `offsetLeft`/`offsetTop`, а не `getBoundingClientRect`** — вони
  дають РОЗКЛАДКОВУ позицію й не бачать `transform`, тож повторний замір під
  час циклу не накопичує похибку. Та сама функція працює на 390 і 1280 без
  гілки: зсуви міряються, а не задаються.
- Кадр `0%` мусить бути **легальним**: під пресетом `calm` (`--loop-state:
  paused`, але `--motion: 1`) цикл застигає саме на ньому.
- Кожна `infinite` несе `animation-play-state: var(--loop-state)` — той самий
  токен, що пише кнопка паузи, спостерігач видимості й `IntersectionObserver`.
  Три незалежні причини зупинки тримаються трьома прапорцями, а пишуть один токен.
- **Скидання циклу — `fade`, не `reverse`.** `reverse` механічно кращий
  (розрив 35 px проти 406), але означає, що робота сама себе скасовує. Розрив
  ховається під `opacity ≤ 0.10` на кадр: `96% {op:0, кінець} → 97% {op:0,
  початок} → 100% {op:1, початок}` — перенесення під прозорістю.
- **Темп — множник у складеному токені** (`calc(<L1> * var(--pace) * var(--dur-u))`),
  зареєстрований через `@property`. Гасне тим самим механізмом; три пресети
  перемикаються атрибутом на `<html>`.
- **Лічильники — два текстові вузли в ОДНІЙ комірці `inline-grid`**, другий
  `aria-hidden`; перемикаються `opacity` зі `steps(1, end)`. Нуль вставок у DOM,
  нуль стрибків ширини (`tabular-nums`), скрінрідер читає дошку один раз.

**`animation-timeline: scroll()`** гаситься не медіа-запитом, а розведенням:
анімація рухає число (`@property <number>`), а `transform` множить його на
`var(--motion)`. При `reduce` множник 0 — ефект зникає, медіа-запит не правився.
