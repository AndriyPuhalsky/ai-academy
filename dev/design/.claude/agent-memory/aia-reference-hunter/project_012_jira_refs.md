Закрито 2026-10-01. Вихід — `dev/design/012-jira/02-references/`
(`index.html` + `data.json` + `build.js` + `shortlist.md` + `lab/` ×2 + `shots/` 68, **5,0 МБ**).
145 унікальних адрес переглянуто, 87 повний інструментальний триаж, 25 відібрано з кадрами
на 350 / 768 (+1440 для hero).

**Why:** повторно міряти ці сайти немає сенсу — числа лежать у `data.json` і відтворюються
`build.js`. Перед новою добіркою на дотичну тему звірятись із цим списком.

## Негативні результати, які не треба перевідкривати

- **Імітованого курсора, що тягне обʼєкт у UI, немає на жодному з 18** перевірених
  (зокрема Arcade / Storylane / Navattic / Supademo — платформи, які демо й продають;
  їхній власний найбільший рух у hero — **7 px**). Найближче — Figma: курсори **присутні**,
  але нічого не тягнуть.
- **Мітки-номера на самій схемі в DOM немає на жодному з 40.** Схему всюди малюють растром.
  ⚠ Але **нумерована легенда** через `counter()` є: M3 **60**, gwern 142, Tufte 6, Carbon 6,
  Stripe 4.
- **Кнопку «пауза» при циклі > 5 с має 1 сайт із 14** (Figma, цикл 25 000 мс).
  Цикл, що стоїть поза екраном, — **1 із 10** (cal.com). `reduce` реально гасить цикли
  у **4 із 10**: Linear гасить 6 із 82, Cursor 0 із 36, Raycast 0 із 8.
- **Кегль у мок-вікнах:** Attio **3 px**, Clerk 8–11, Basedash/Raycast/Linear 10, Cursor 10,3.
  ≥ 12 px тримає лише **shadcn/ui** — бо це справжній компонент, а не малюнок компонента.
- **Усі трекери показують себе скріншотом** (Plane, Asana, Monday, Teamhood, Shortcut,
  Huly `mediaRatio` 3,883): DOM-вікон 0, руху 0.
- **«Анімований hero» на практиці = марка з логотипами** (Monday 567 px, Arcade 746,
  Shortcut 538, Storylane 520, Supademo 237).
- **Стан спокою без JS:** Linear **55 видимих / 926 прихованих**, CS50 **0 / 3 363**,
  roadmap.sh 276 / 1 182. Повний тримають 4 із 14: Figma, shadcn, Resend, gwern.
- **roadmap.sh / Odin / MDN Curriculum — SVG** (242 / 118 / 141 `path`), не DOM.

## Значення, що вже заміряні (не міряти вдруге)

Linear поява рядка `h1` `opacity` 0,49→1 + 6–9 px / **518 мс** · Raycast `fade-in-up`
**1 000 мс**, стагер через `delay` = `duration` · Pitch **600 мс ease-out**, крок **200 мс** ·
Navattic **2 000 мс cubic-bezier(.25,.1,.25,1)**, фон `opacity` 0→**0,4** · Figma цикл
**25 000 мс linear ∞**, курсор до 967×814 px, прихід 1 250 мс, дрібні 150 мс ease-out ·
Cursor каретка `pulse` **2 000 мс**, перехід **200 мс cubic-bezier(.4,0,.2,1)** ·
Raycast каретка **1 100 мс**.
Поверхні: shadcn радіус **8** / межа 1 px білого 10 % / без фону й тіні · Basedash 20 ·
Resend 24 + межа `rgba(214,235,253,.19)` · Attio/Cal/Clerk 12 + тінь 3–4 шари.
**Темні вікна = межа без тіні, світлі = тінь без межі** (3 з 3 і 3 з 3).
Чип легенди M3: `::before content: counter(item)`, **24 × 32**, радіус 12, фон
`rgb(48,48,48)`, 14 px/500, **`line-height: 32px`**, `margin-left: -36px`.
Мітка gwern: **`line-height: 6px`** при тексті 20 px — ось чим тримається «не зсуває рядок».

## Лабораторії (у `lab/`, відтворюються за хвилину)

`rest-state.html` — три способи автора × три умови. 🔴 **Спосіб «JS знімає `data-hide`»
ламається так само, як «ховає CSS»** (без JS 0 із 31 знака), якщо атрибут стоїть у поданому
HTML. Виживає лише «спокій = фінальний кадр» (31/31/31).
`loop-reset.html` — скидання циклу: `jump` розрив **406 px**, `fade` 406 px але під
`opacity` ≤ 0,10/кадр, `reverse` **35 px** (але хибний зміст: робота сама себе скасовує).
Крок колонки 210 px, найдовший кадр 18 мс у всіх шести прогонах.
