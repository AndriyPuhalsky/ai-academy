Набір прийомів, перевірених на задачі 005. Економить півгодини на кожній наступній валідації.

**Працює як доказ:**
- **Копіювання:** `left_click_drag` по блоку → `cmd+c` → клік у створену через JS
  `<textarea>` → `cmd+v` → порівняти з `textContent`. Це справжній буфер обміну, на
  відміну від `Range` + `selection.toString()`. Робити обидва: `Range` для всіх блоків,
  живу мишу для двох найризикованіших.
- **Контраст:** обхід усіх текстових вузлів із розрахунком накладених фонів і альфи —
  ловить те, чого `grep` по CSS не бачить (успадковані класи з інших файлів).
- **Тривалість анімації:** `gsap.globalTimeline.getChildren(false,false,true)[0].duration()`
  — авторитетне число з живого екземпляра, працює навіть у прихованій вкладці, на відміну
  від rAF-лічильника.
- **Вузькі ширини:** тільки через iframe-проксі. Десктопний Chrome не дає вікна вужчого за
  ~500px і **мовчки віддає скріншот більшого в'юпорта** — на цьому легко зробити хибний
  висновок про «зламану мобілку».
- **`prefers-reduced-motion`:** окремий запуск `--headless=new --force-prefers-reduced-motion
  --screenshot`. Системне налаштування доступності не чіпати.
- **WCAG 2.4.11:** прокрутити елемент так, щоб він був трохи вище в'юпорта, потім `.focus()`
  і виміряти `getBoundingClientRect().top` проти висоти липкої шапки. Липка шапка + фокус
  = дефект за замовчуванням, поки немає `scroll-margin-top`.

**Дає хибний результат / не працює:**
- **Прихована вкладка** (`document.visibilityState === 'hidden'`) — Chrome не крутить
  `requestAnimationFrame`, GSAP стоїть, `IntersectionObserver` не спрацьовує. Виглядає як
  «анімація зламана», хоча вона просто не грає. **Перевіряти `visibilityState` перед
  будь-яким виміром руху.** Повернути вікно у видимість із сесії агента не вдалось:
  `resize_window`, нова вкладка, нова група, `open -a` — не допомогло; `osascript` до
  Chrome вішається на дозвіл Apple Events.
- **Синтетичні клавіші** розширення не викликають нативного скролу — тест «скрол стрілками
  всередині блока» недійсний, а не провальний.
- **`--virtual-time-budget` у headless НЕ прокручує rAF** — три скріншоти на 1.5/2.5/3.5 с
  вийшли побайтово однакові. Проміжні кадри анімації в headless зняти неможливо.
- Виміри `first-contentful-paint` у прихованій вкладці — сміття (3548 мс на локальному
  сервері).
