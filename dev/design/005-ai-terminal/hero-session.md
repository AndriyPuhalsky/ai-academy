# Вміст hero-сесії — вхідні дані для макета

**Джерело:** коренева сесія `dev_03_09`, 2026-09-03. Складено під контракт §5.4 спеки
(12–14 рядків; ≤ 56 символів широкий варіант, ≤ 42 вузький).
**Статус: робоча заглушка.** Точний фінальний текст коренева сесія звірить із реальним
запуском на оновленій збірці й надішле перед версткою. Композиція має витримати підміну.

Сценарій проходить усі **чотири стани** hero (рішення власника, `00-decisions.md` §3):
промпт → крок інструмента → диф → діалог дозволу. Задача навмисно найпростіша з можливих:
людина без досвіду має зрозуміти **що саме сталось**, а не вразитись складністю.

## ⚠️ Глифи: що перевірено, а що ні

Коренева сесія перевіряла кожен символ окремо, і результат **неоднорідний**:

| глиф | статус | джерело |
| ---- | ------ | ------- |
| `❯` | **перевірений** | живий вивід `claude plugin list`, `00-research/screens/b-plugin-list-live.txt` |
| `⏺` | **не перевірений — стилізація** | прототип, схвалений власником візуально |
| `└─` | **не перевірений — стилізація** | те саме |

Чому не перевірити: офіційна документація навмисно не показує відрендерений вивід
терміналу (у quickstart немає жодного такого блока), а бінарник (317 МБ, запакований)
не віддає UTF-8 ні через `grep`, ні через `strings`.

**Схвалення власника стосується вигляду, а не доказу, що інтерфейс малює саме ці символи.**

## Наслідок для розмітки — обов'язковий, не рекомендація

**Не закладати композицію на точну ширину `⏺`.** Це широкий глиф; якщо реальний інтерфейс
малює інший, підміна зсуне все праворуч від нього.

**Вимога:** маркер кроку — **окремий елемент із фіксованою шириною колонки**, а не частина
текстового рядка. Тоді заміна символу нічого не ламає: змінюється гліф, а не сітка.

Те саме стосується `└─` — префікс результату під кроком тримати окремою колонкою.

Побічна вигода, яку варто взяти свідомо: винесений в окремий елемент маркер можна закрити
`aria-hidden="true"`, і скрін-рідер перестане читати «чорне коло» перед кожним кроком.
Зараз, коли `⏺` живе всередині тексту, це неможливо.

## Версії

Числа версій у макеті — **заглушка**. Точне значення дасть коренева сесія перед версткою:
курс орієнтується на канал `latest`, а не на homebrew stable (у homebrew два каски —
`claude-code` відстає приблизно на тиждень від `claude-code@latest`).
