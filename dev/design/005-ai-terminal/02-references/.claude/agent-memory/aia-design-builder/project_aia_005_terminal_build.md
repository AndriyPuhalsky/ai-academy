Макет лендінга «AI Термінал» + компонента `.term` зібраний у
`dev/design/005-ai-terminal/03-build/` (index / lesson / components + tokens/term/page CSS
+ render/term/motion JS + чернетка `claude-code.config.json`).

**Why:** третій блок платформи з нуля; роль термінала — «Акцент ≈29%» (рішення власника
після референсів), карта програми — рейка фаз + «зміст книги», іспит окремим вузлом,
довідники окремим входом («полиця біля столу»).

**How to apply:** беручи наступну дизайн-задачу AIA, звірятись із цими рішеннями, а не
винаходити наново. Зафіксовано в макеті:

- **Естетичний ризик — «стіл»:** на всій сторінці рівно ОДИН об'єм — тепла плита
  `--c-desk: #1A1714` під терміналом, одна тінь, одне джерело світла. Причина не смак:
  полотно термінала `#0d0c0b` темніше за сторінку `#141312`, тож без плити термінал
  читається як діра, а не як предмет. Ризик повністю зворотний (3 токени + 1 div).
  Наявний `.hero-glow` на цій сторінці свідомо не вживається — два джерела світла
  вбивають ефект предмета.
- **Композиція:** одна пряма вертикальна вісь від hero до вузла іспиту, заповнюється
  скролом (один ScrollTrigger). Це НЕ змійка 003 — розмахів, SVG і пульсуючого кільця
  немає (бриф їх забороняє).
- **Матеріал кодує тип об'єкта:** тепла плита `--c-desk` = «річ, що лежить під рукою»
  (термінал, довідники); гола лінія без матеріалу = «крок шляху» (модулі).
- **Маркери `⏺` / `└─` / `❯` — окремі елементи фіксованої ширини колонки** (1ch / 2ch), а
  пробіл після маркера лишається справжнім символом рядка. Тому копіювання дає рівно те,
  що видно, і глиф можна замінити, не зсунувши сітку.
- **Друк тексту — `clip-path: inset()` + `steps(N)` по символах**, каретка на зовнішньому
  шарі, `@property --rev { inherits: true }`. Посимвольна вставка в DOM заборонена.

**Відкрите на момент здачі:** вміст hero-сесії — заглушка за формою контракту (реальний
текст дасть коренева сесія); шість назв модулів у макеті відрізняються від `program.md`
(запропоновано прибрати англійські терміни — рішення за авторами курсу); анімацію в русі
я не бачив жодного разу (див. [[headless-visual-check]]).
