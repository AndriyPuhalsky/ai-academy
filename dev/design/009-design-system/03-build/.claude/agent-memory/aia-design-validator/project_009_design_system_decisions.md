Задача 009 (єдина дизайн-система AIA) пройшла всі чотири агенти 2026-09-07. Здача —
`dev/design/009-design-system/04-variants/`: `_base/` (виправлена система), `variant-a|b|c/`,
`compare.html`, `verdict.md`. **Джерело правди після конвеєра — `_base/`, а не `03-build/`**
(у 003 повторне перенесення з `03-build` принесло б назад уже виправлений дефект).

**Виправлено валідатором у `_base/` — не «лагодити по дорозі» в 010:**
- **Блокування скролу діалогу** (`html.ds-lock`) — його не було взагалі, критерій спеки
  провалено. У проді для цього вже є прийом `html.aia-scroll-lock` із 004.
- **Підложка діалогу** `place-items: safe center` + `overflow-y: auto` +
  `overscroll-behavior: contain`. Було `place-items: center` без overflow — на 360×420
  картка 707 px не була досяжна цілком. Це четвертий раз, коли модалка AIA ловиться на
  короткій ВИСОТІ вікна.
- **`.ds-fld__input` прибрано з набору `[data-lit]`** («світло згори»): ефект опускав
  верхній кант поля до 2.22/2.08 при нормі 3:1 для межі контрола. Поверхні (картка,
  врізка, `.term`) ефект зберігають.
- **Епсилон гасіння руху 0.0004ms → 0.00002ms.** Епсилон МНОЖИТЬСЯ на сире число токена,
  тож 0.0004 було безпечно лише до 2500 одиниць L1. Ключ: `transitionend` приходить на
  наступному кадрі, а не «через тривалість», тому менший епсилон нічого не коштує.
- **`ds-note__title` більше не `<h4>`, а `<p>`** — інакше кожна врізка в кожному уроці
  ламала б структуру заголовків на 26 сторінках.
- `tokens-render.js` більше не читає складений токен `--dur-exit`, а бере
  `AIA.motion.dur("exit")` — читання складених токенів із JS і є та пастка, задля якої
  побудований увесь механізм `@property`.

**Знахідка, яку НЕ виправляв, але 010 не має успадкувати:** числа тонів у `NOTES.md`
пораховані **в HSL**, хоч у тексті сказано «OKLCH». Відтворив: 21.6 / 22.8 / 133.2 / 54.2
— це рівно HSL. У перцептивній шкалі найтісніша пара не «шафран ↔ warn» (32.1° OKLCH),
а **`ok` ↔ акцент AI Architect, 26.7°**. Критерій «≥30° між курсами» проходить в обох
шкалах, тож приймання це не міняє.

**Числа, які знадобляться:** вага шрифтів A 155.9 / B 244.0 / C 172.0 КБ · крок моно
JetBrains і Geist 0.600em, Martian Mono 0.700em · 60 fps на всіх трьох варіантах, нуль
кадрів > 32 мс навіть при CPU ×6 · довгі кадри бувають лише на холодному старті
(шрифти + GSAP), повтор дає нуль.

**Незакрите:** паритет із Figma (квота MCP вичерпалась і в білдера, і в мене — один
виклик, більше не пробувати того ж дня) · компонент-сети у Figma не зібрані · мобільні
вʼюпорти в референсах не міряні взагалі · ширина колонки для уроків → 010 · Safari не
перевірявся.
