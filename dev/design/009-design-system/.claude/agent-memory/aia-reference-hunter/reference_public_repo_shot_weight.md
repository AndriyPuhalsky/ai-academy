`dev/design/` лежить у git і репозиторій публічний (`dev/design/CLAUDE.md`, правило №2).
Тому папка `02-references/shots/` — це не тимчасовий кеш, а те, що поїде в історію назавжди
(видалити файл пізніше = він лишається в старих комітах).

**Що робити наприкінці добірки, перед здачею:**
1. Зібрати список кадрів, які реально згадані в `data.json` і в `index.html`.
2. Видалити решту. На 009 це було 100 із 182 файлів.
3. Стиснути ті, що лишились: `sips -s format jpeg -s formatOptions 72 -Z 1400 f.png --out f.jpg`
   (лабораторії з текстом — `-Z 2000`), тоді регексом замінити `.png` → `.jpg` у `data.json`
   і перезібрати сторінку.

Результат на 009: **60 МБ → 12 МБ** без видимої втрати якості на скріншотах сайтів.

**Why:** 60 МБ бінарників в історії публічного репозиторію — це назавжди, і жодної користі
від невикористаних кадрів немає.

**How to apply:** робити це останнім кроком, після того як `index.html` уже зібрано —
інакше доведеться правити посилання двічі.
