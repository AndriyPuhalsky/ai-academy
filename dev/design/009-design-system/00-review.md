## Уточнення агента №1 до цього файла (2026-09-07) — мають перевагу

Агент №1 переміряв код власним `grep`ом і знайшов, що чотири місця першої редакції були
надто мʼякими. Повний розбір — `01-spec.md` §3; коротко:

1. **Кнопок не шість, а дванадцять** CSS-означень + сімʼя інлайн-утиліт: **сім різних
   висот** (24 / 32 / 33 / 37 / 40 / 41 / 44 / 48) і **чотири радіуси** (4 / 6 / 8 / 8.8).
   `.aia-submit[disabled]` оголошений двічі з різними значеннями (`custom.css:1697` і
   `:2079`) — перше мертве.
2. **Кольори: палітра з 11 значень описує сайт із ~17 сходинок.** Пʼять поверхонь живуть
   поза палітрою: `#1B1916` ×5, `#171513` ×3, `#332E29`, `#201C18`, `#57504A`.
   **Стани мають три незалежні джерела**: квіз — хардкодом, термінал — токенами, помилка
   форми — це сам акцент. Найслабша ділянка системи.
3. **Гасіння руху — 57 поіменних рядків трьох поколінь**, не «кілька блоків».
4. **Пастка, яка мовчки ламає GSAP:** `getComputedStyle()` для незареєстрованого токена
   повертає невирахуваний рядок `calc(180 * calc(1 * 1 * 1ms + 0.001ms))` → `parseFloat`
   дає `NaN` → наявний помічник `ms()` (`js/roadmap-motion.js:60`) тихо бере fallback,
   і рух лишається живим навіть при `prefers-reduced-motion`. Закривається двома
   правилами одночасно: JS читає лише сирі `--p-*`, а складені токени реєструються через
   `@property`. Виміряно в Chrome: після реєстрації той самий виклик повертає `0.18018s`
   при `--motion:1` і `0.00018s` при `0`.
