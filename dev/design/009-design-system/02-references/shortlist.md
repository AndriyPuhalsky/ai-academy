## Типопари — вісь варіантів (Д2). Приношу чотири, зібрані й показані

Скріншот: `shots/lab-typepairs.jpg`. Усі гарнітури: OFL 1.1 · рендер-тест 18 українських гліфів пройдено · є у переліку Figma з `00-review`.

| | Характер | Display / Sans / Mono | Вага (latin+cyrillic) | Ризик |
| - | -------- | --------------------- | --------------------- | ----- |
| **A** | дідона високого контрасту — «дорого» найкоротшим шляхом | Prata / Golos Text / JetBrains Mono | 19+117+79 = **215 КБ** | Prata має один накрес, тонкі штрихи на темному не витримують дрібного кегля |
| **B** | широкий дисплейний гротеск — «захопливо», найдалі від поточного | Unbounded / Onest / Martian Mono | 33+97+67 = **197 КБ** | Martian Mono має крок 0,7em — рядок термінала на 17 % ширший |
| **C** | важкий дисплейний серіф — «серйозно» з запасом | Yeseva One / Commissioner / Geist Mono | 17+123+70 = **210 КБ** | Reserved Font Name «Yeseva»; Geist Mono тягне асоціацію з Vercel |
| **D** | резерв: український слід | Arsenal / Wix Madefor Text / JetBrains Mono | 17+68+79 = **164 КБ** | Arsenal має лише 400/700 — третьої ваги для UI немає |

**Моя рекомендація як точки відліку (варіант A агента №3): пара A.** Причина не смак, а вимірне: Prata дає найбільший
контраст характеру між заголовком і текстом при найменшій вазі (19 КБ на всю дисплейну роль), Golos Text має три ваги
для UI, а JetBrains Mono має крок 0,6em — той самий, що в нинішнього IBM Plex Mono, тож 101 блок `.term` і колонки
маркерів 1ch/2ch не доведеться переміряти. **B — найсильніший кандидат у «свідомий зсув»**, бо він єдиний з чотирьох
не схожий на поточний сайт узагалі.

## Три прийоми, які варто взяти обовʼязково

1. **Драбина Radix із роллю на кожній сходинці** — 12 названих сходинок замість наших ≈17 безіменних, і готові стани
   ok/warn/err/info, які **не є акцентом**: `green-11 #3dd68c`, `amber-11 #ffca16`, `red-11 #ff9592`, `blue-11 #70b8ff` —
   усі чотири проходять AA на всіх трьох наших поверхнях (мінімум 7.4:1).
2. **Подвійне кільце фокуса** `box-shadow: 0 0 0 2px <фон>, 0 0 0 4px <акцент>` — знайдено незалежно у Geist,
   Supabase Docs і basement.studio. На темному воно читається там, де звичайний `outline` зливається з полотном термінала.
3. **Драбина тривалостей із призначенням у назві** (Carbon: 70/110/150/240/400/700 мс, кожна з рядком «для чого»).
   У нас сьогодні ~35 тривалостей із трьох задач і жодної драбини.

## Чого свідомо уникати

- **Стагера як фірмового прийому.** З пʼяти преміальних сайтів, просканованих на інкрементні затримки, стагер має **нуль**.
  Виміряно в лабораторії: 30 карток без cap = 2249 мс очікування, з cap 8 = 982 мс.
- **Білого тексту на акцентній заливці.** Наш `clay #D97757` під білим дає **3.12:1** — `--c-on-accent` мусить бути темним.
- **Кроку 8 Radix як межі контрола.** На наших поверхнях він дає 2.95 / 2.73 / 2.48 — для §5.1.2 брати крок 9 або 10.
- **Референсів, де рух живе в canvas** (Rive: 0 CSS-переходів і 125 IntersectionObserver) — не наш стек.

## Три речі, які добірка знайшла в чинному проді

1. **`quiz bad #C0564F` провалює AA на всіх трьох поверхнях** (4.14 / 3.82 / 3.48) — це колір «неправильна відповідь» на 57 сторінках уроків.
2. **`term-err #C97070` провалює AA на `raised`** — 4.48 проти 4.5, за два соті.
3. **Український апостроф `ʼ` (U+02BC) лежить у латинській підмножині Google Fonts, не в кириличній.** Сторінка, яка
   вантажить «тільки кирилицю», лишиться без апострофа. Гривня `₴` не входить у жодну з двох.

## Що я вирішив за спеку і позначаю

- **Пара C змінена з Bona Nova на Yeseva One.** Причина: Bona Nova немає в переліку Figma, який фактично перевірив
  `00-review`, а Yeseva One там є. Bona Nova і Brygada 1918 лишились у другій лінії — кирилиця в них справжня.
- **Приніс чотири пари замість «2–3»** — четверта (Arsenal) є єдиною відповіддю на питання «а якщо власник захоче
  український авторський слід», і вона найлегша за вагою.
- **Антиреференси приніс з вимірами, а не списком** — Р7 забороняє брати їх у референси, але не забороняє показати,
  чим саме вони погані.
