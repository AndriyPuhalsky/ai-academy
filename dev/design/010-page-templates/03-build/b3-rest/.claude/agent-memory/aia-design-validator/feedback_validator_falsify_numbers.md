**Правило: жодне число зі звіту білдера не потрапляє в пакет як факт, поки я не переміряв
його сам.** Достатньо одного скрипта на Python по репозиторію або одного обходу CSSOM.

**Why:** головний урок задач 005 і 009 — перевірка автором власної роботи не рахується.
У 010 підтвердилось конкретикою: з шести перевірених тверджень **три** не збіглись.

| Твердження | Перевірка |
| --- | --- |
| «найдовша таблиця довідника 111 рядків» (Б3) | **39**. Завищено втричі |
| «десять правил `:hover` у системі» (усі троє) | **22**: 10 у базі + 9 у `roadmap.css` + 3 у дельтах. Роадмапні не побачив ніхто |
| «767 рядків терміналів, 39,0 % / 33,1 %» (Б2) | **677**, **45,3 % / 38,4 %**. Різниця між варіантами та сама, абсолютні числа інші |

І три збіглись точно: 540 альфа-модифікаторів у 72 файлах · 182 таблиці, у `modules/`
медіана 5 і максимум 18 · найдовший рядок термінала 222 символи.

**How to apply:** три найдешевші й найрезультативніші перевірки:
1. **Python по репозиторію** — рахувати таблиці, рядки, класи, вживання. Хвилина роботи,
   ловить завищені числа.
2. **Обхід CSSOM у живому браузері** — саме він знайшов 12 незахищених `:hover`, яких не
   бачив жоден `grep` по одному файлу (правила лежали в трьох різних файлах).
3. **Вставити живий елемент і подивитись, що згенерувалось** — так підтверджено, що
   прапорець Tailwind `future: { hoverOnlyWhenSupported: true }` справді працює на CDN.

Найкорисніша знахідка йде не з перевірки «чи правда те, що написано», а з питання
**«а що вони МОГЛИ не перевірити, бо це не їхня зона»**. Дефекти в `roadmap.css` знайшлись
саме так: усі троє чинили правила `_base`, і нікому не спало на думку перевірити власні.
