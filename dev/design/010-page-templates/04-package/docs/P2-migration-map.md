# П2 · Карта міграції: старий клас → новий

**Покриття — 100 %.** У проді (66 HTML + 15 `js/*.js` + 3 `css/*.css`) є **390** власних імен
класів; рядок нижче має **кожне з 390**. Перевірка машинна: список імен із проду мінус
список імен у карті = порожньо. Робив її валідатор сам, а не переказував зі спеки.

## Як читати

| Колонка | Значення |
| ------- | -------- |
| **×** | скільки вживань переміряно (HTML + JS разом). `0` = імʼя живе лише в `css/custom.css` — тобто мертвий код або клас, що збирається конкатенацією |
| **розмітка** | `—` клас міняється на місці · `+` треба **дописати** клас поруч · `структура` — треба міняти теги або вкладеність |
| **скрипт** | `так` — заміна одним `sed`/regex безпечна · `ні` — **тільки руками** · `js` — імʼя народжується в `js/*.js`, у HTML його немає, міняти треба там |

⚠ **`0` вживань не означає «видалити».** Девʼять класів роадмапа (`rm-node--done`,
`rm-row--done`, `rm-rows--done`, `rm-count--progress`, `rm-row__plat-mark--*`) збираються
конкатенацією в JS: `"rm-row rm-row--" + it.state`. Шість класів термінала
(`term__add`, `term__del`, `term__foot`, `term__status`, `term--long`, `term__fade`)
реалізують стани 5–8, які просто ще не використані в контенті. **Не видаляти.**
