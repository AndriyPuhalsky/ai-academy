# П4 · Пастки

**Кожна вже колись ламала цей проєкт або була заміряна під час цієї задачі.** У кожної —
**механізм** (чому так буває) і **ознака** (як помітити, що вона спрацювала). Ознака важливіша
за механізм: майже всі ці пастки **мовчазні** — ні помилки в консолі, ні падіння збірки.

## Найкоротший спосіб не наступити

Ці пʼять коштували найдорожче. Якщо читати нема часу — читати їх.

| № | Одним реченням |
| - | -------------- |
| **21** | `bg-ink/85` після заміни теми стає **повністю прозорим** — липка шапка зникає. 540 таких класів |
| **2** | Tailwind preflight стоїть у каскаді **пізніше** за наші файли — будь-яке правило на голий тег мовчки не діє |
| **6** | Перейменувати токен у CSS і забути в JS = сторінка анімується **старими зашитими числами**, і це виглядає нормально |
| **10** | У фоновій вкладці `requestAnimationFrame` **не викликається взагалі** — будь-який замір руху там бреше |
| **8** | Клас, що приходить у DOM лише з JS, Tailwind генерує через ~53 мс. Це вже давало зсув **64,8 px** |
