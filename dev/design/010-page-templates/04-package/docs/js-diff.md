# Дифф до `js/` — 13 із 15 файлів мігрують

Зведено з трьох звітів білдерів. Бриф 010 припускав, що шаблон не чіпає скрипти; насправді
**471 Tailwind-утиліта і 388 імен класів народжуються саме в JS**.

**Не міняються два файли:** `js/auth.js` (шар даних Supabase) і `js/progress.js`.

**Еталонні реалізації — `files/js/reference/`.** Це **не файли для копіювання**: вони писались
під макет і не знають про Supabase, прогрес і реальні дані. Дивись у них **як** зроблено,
переноси **за таблицями нижче**.

| еталон у пакеті | відповідає файлу проду |
| --------------- | ---------------------- |
| `chrome-ui.js` | `js/ui.js` (дропдаун, мобільне меню, шторка) + розмітка слота в `js/auth-ui.js` |
| `landing-config.js` | `js/config.js` |
| `claude-code-render.js` · `claude-code-motion.js` | однойменні |

## Правило, яке стосується всіх файлів

**Жоден клас, що приходить у DOM тільки з JS, не має бути Tailwind-утилітою.**
Tailwind CDN генерує такий клас через ~53 мс після вставки — виміряно в 006 D-02, зсув
**64,8 px**. Замінюється або компонентним класом `ds-*`, або утилітою, яка **вже є в
статичному HTML тієї ж сторінки**.

Перевірка: `grep -nE 'class(Name)?\s*=\s*["\x27\x60][^"\x27\x60]*(rounded-|grid-cols-|space-y-|gap-x-|mt-|mb-|px-|py-|w-full|p-[0-9])' js/*.js` → має бути порожньо.

**35 утиліт зі списку §8.9 спеки** (найгустіше — `js/config.js`): `rounded-2xl`, `w-full` ×7,
`mt-5`, `p-8`, `justify-center`, `gap-x-4`, `sm:gap-x-6`, `sm:px-6`, `items-baseline`,
`space-y-3`, `mt-auto`, `w-fit`, `grid-cols-[auto,1fr]`, `sm:grid-cols-[auto,1fr,auto]`,
`mb-5`, `pt-1`, `mt-1.5`, `group`, `hover:border-clay/50`, `opacity-0`,
`group-hover:opacity-100`, `bg-surface/60`, `whitespace-pre-wrap`, `break-all`, `h-full`,
`items-start`, `space-y-4`, `resize-none`, `text-right`, `fixed`, `z-[60]`, `bg-ink/80`,
`p-4`, `border-clay/50`, `border-clay/60`.
