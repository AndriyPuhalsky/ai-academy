# Чеклист після кожного етапу

Формулювання навмисно машинні: «має бути на екрані» або «має вивести команда».
Якщо хоч один рядок етапу не сходиться — **далі не йти**, бо наступний етап стоїть на цьому.

**Як дивитись:** `python3 -m http.server 8000` з кореня репозиторію.
Прод-порівняння: https://ai-academia.com.ua · дев-превʼю:
https://dev-ai-academy.andriy-puhalsky.workers.dev

## Перевірка, яку варто робити після **кожного** етапу, а не лише в кінці

1. **Консоль порожня.** Одна помилка сьогодні — десять зламаних сторінок післязавтра.
2. **320 px.** Найдешевший спосіб побачити, що щось розпирає документ.
3. **`prefers-reduced-motion`.** Найдешевший спосіб побачити, що токен руху не зареєстрований.
4. **Ctrl+F5.** ⚠ Кеш-бастер на HTML **не рятує від кешу CSS/JS**. Якщо зміна «не застосувалась» — спершу перевір це, а не код.
