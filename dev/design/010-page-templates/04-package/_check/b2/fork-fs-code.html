Кегль коду на екрані вужчому за 640

Прод дає 12 px нижче 640 і 13,52 вище. Система 009 — плаский 13,52 на всіх ширинах. Обидва кадри нижче — той самий урок, той самий термінал, вʼюпорт 390 px.

i Що саме тут вирішується

Не «читабельність» — 12 і 13,52 px обидва читабельні. Вирішується, скільки символів термінала видно без горизонтального скролу. Уроки курсу «AI Термінал» — це 767 рядків справжнього виводу CLI, і рядок довжиною 82 символи там не рідкість: це 95-й процентиль.

Різниця у видимих символах — п'ять (38 проти 43), тобто 13 %. Різниця у кількості рядків, які взагалі не вміщаються, — теж невелика: переміряно по всіх 767 рядках терміналів у 56 уроках, при 13,52 px не вміщається 39,0 % рядків, при 12 px — 33,1 %. Тобто зменшення кегля не прибирає горизонтальний скрол: воно прибирає його для одного рядка з шістнадцяти, а решта скролиться однаково.

За плаский кегль — уся добірка мобільних референсів 010: кегль коду на телефоні не зменшує ніхто, Laravel і MDN тримають 16 px. Проти — наш власний вміст із рядками на 222 символи.

Ціна помилки асиметрична й мала: це один рядок у tokens.css (@media (max-width: 640px) { :root { --fs-code: var(--p-fs-label) } }), і його можна додати або зняти в будь-який момент без жодної правки розмітки.
